# 学业规划细则（最高责任层）

> **inherits_from**: `JUNSHI-ENG-MASTER-001`

## 1. 目的

把母文件「学业规划为最高责任/上层建筑」落到可代码的规划对象链、字段、状态机与接口契约。规划不是生成计划表，而是基于真实位置、阶段目标、约束与可核验证据，持续形成/执行/检验/修正一条可理解、可行动、可调整的学业路径。`[终局] L404-405`。

## 2. 范围

- 覆盖规划对象链：位置、阶段目标、差距及成因、路径与优先级、任务、教与授、检验、反馈、修正、阶段衔接。`[终局] L405, L767`。
- 教与授、任务、反馈、复盘服务规划，不取代规划对路径的裁决。`[终局] L474`。
- **不做**: 不决定具体学段/学科内容、具体教学方法/界面像素；不替判断引擎/专项 Agent 做专业判断。`[母文件] §0.1`。

## 3. 输入 / 输出

| 输入 | 输出 |
|---|---|
| 判断引擎的结构化判断候选（位置/目标/差距/路径）`[终局] L518` | 生效规划 / 修正（版本化、可回退）`[终局] L865` |
| 证据（外部+内部）`[终局] L796-807` | 任务 + 教与授要求 + 资源安排 `[终局] L790` |
| 现实约束（课程/考试/时间/资源）`[终局] L788` | 阶段衔接资产候选 `[终局] L467` |
| 反馈/检验结果回流 `[终局] L899` | 未决/待确认/待验证项 `[终局] L790` |

## 4. 责任

- 规划层承担 10 项最终责任（不可下放）：全局学业位置、阶段目标、差距分析、路径设计、路径最终权威、任务与资源全局安排、执行与检验统一监测、动态修正裁决权、阶段衔接职责、对学生的最终承诺。`[终局] L458-468`。
- 判断引擎提供候选不拥有裁决权；专项 Agent 提供专业意见不形成全局规划；教与授/任务服务规划。`[终局] L470-476`。

## 5. 规划对象链与字段定义（可落 JSON Schema）

```text
当前位置 → 与目标比较 → 差距及成因 → 在现实约束下形成候选
→ 路径与阶段顺序 → 分解 → 任务与教与授 → 学生执行
→ 检验与结果 → 反馈 → 规划继续/调整/暂停/回退
→ 经确认/受控提炼 → 学业资产 → 下一轮规划
```
`[终局] L809-829`。任何节点可因证据不足/冲突/权限/学生拒绝而降级暂停回退。

### 5.2 规划最小输出（一次可成立规划至少包含）`[终局] L790`

规划对象和适用学生/阶段；基于证据的位置描述；目标及来源；差距及证据；现实约束；路径和阶段顺序；当前最小任务；所需教与授/资源；完成定义和检验方式；反馈如何影响下一步；未确认/待验证风险项；规划版本有效范围和回溯。**没有目标/差距/路径/任务/检验条件的内容只能称分析或建议，不能称完整规划。**

## 6. 规划状态机

| 状态 | 触发 | 条件（证据/权限） |
|---|---|---|
| `draft`（草案） | 初始规划候选生成 | 基于证据/目标/约束 |
| `candidate`（候选） | 判断引擎产出 | 候选不经规划层裁决不生效 `[终局] L794` |
| `active`（生效） | 规划层裁决 | 高影响变更须必要确认 `[终局] L792` |
| `paused`（暂停） | 证据不足/需确认/高风险 | 保留状态/版本/证据/待决，不当作完成或失败 `[终局] L867` |
| `rolled_back`（回退） | 证据证伪/重大约束变化 | 回到上一稳定版本或基于旧状态新版本 `[终局] L867` |
| `ended`（结束） | 达成目标/取消/阶段转移 | 写明原因/达成状态/资产候选/未决/数据权限处理 `[终局] L867` |
| `invalid`（失效） | 目标取消/前提证伪/多次检验无效 | 标记失效原因、保留历史、停止沿用 `[终局] L869` |

**候选与生效分离**: 判断引擎只能形成候选；只有规划层能把候选路径变成生效规划。`[终局] L794, L3160`。

## 7. 动态修正（分级触发阈值）

| 级别 | 触发信号 | 影响范围 | 裁决权 |
|---|---|---|---|
| 任务级 | 难度略高/说明不清/教与授不合适/时间微调 | 当前任务解释/练习顺序 | 不改变阶段目标和主要路径 `[终局] L854` |
| 局部路径 | 某知识/能力差距被新证据改变/某学科子路径无效 | 该学科责任域路径 | 重新检查跨学科接口，不自动改整体阶段目标 `[终局] L855` |
| 阶段规划 | 阶段目标无法实现/多局部同向证据/重要考试课程约束改变 | 重评估位置差距资源路径 | 保存旧版本、取得必要确认 `[终局] L856` |
| 全局规划 | 关键事实证伪/目标方向根本改变/违反根级责任 | 冻结重大执行、形成新候选 | 规划层最终裁决，必要时上报人工/责任方 `[终局] L857` |

**触发阈值**（多独立信号/是否触及阶段目标/资源分配/关键节点）`: `[终局] L863`，具体量化阈值 `[待确认]`，不写成已定。

## 8. API / 接口契约

- **输入**（判断引擎→规划）：`JudgmentCandidate[]`（含对象/类型/证据/强度/范围/影响/不确定/建议/确认）。
- **输出**（规划→下游）：`ActivePlan`、`Task[]`、`TeachingRequirement`、`RevisionRecord`。
- **接口**：
  - `plan.evaluate(candidates) → { active_plan | pending_confirmation | rejected }`
  - `plan.revise(trigger_evidence, scope) → RevisionRecord`（版本化）
  - `plan.pause() / plan.resume() / plan.rollback() / plan.end(reason)`
- **失败语义**: 证据不足/冲突/权限/学生拒绝 → 降级补证暂停回退；冲突不静默择一，重大冲突暂停并请求裁决。`[终局] L829, L3160`。

## 9. 完成定义

系统能生成初始规划、识别新证据/变化、判断影响层级、只在符合条件时修正、保留版本原因影响、处理暂停恢复回退结束、交学生简单直白理解、对未定/未验证/冲突保持显式状态。`[终局] L873`。

## 10. 验收标准（L1/L2 首版可验）

1. 任务级变化不无理由改写整体规划；2. 多层影响范围可区分可追溯；3. 单次异常不自动形成稳定学生标签；4. 多来源证据触发适当级别复核；5. 规划修正有证据/原因/影响/版本差异；6. 旧版本未被静默删除；7. 未完成任务不自动归咎学生；8. 暂停/恢复/回退/结束状态有明确条件；9. 失效规划停止产生新任务；10. 学生界面只显示必要变化与下一步；11. 冲突或不确定时降级补证暂停上报；12. 已/未验证边界如实记录。`[终局] L873`。L3 真实使用、L4 教育效果 `[待验证]`。
