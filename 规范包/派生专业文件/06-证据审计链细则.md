# 证据审计链细则（审计设施）

> **inherits_from**: `JUNSHI-ENG-MASTER-001`
> **版本**: v1.0 · **2026-09-15** · **地位**: 不可替换自持核心 · **母源**: 工程开发总文件 §5.1/§7
> **权威锚**: `[终局]` = `访谈资料/学业军师终局访谈/02_访谈记录.md`

## 1. 目的

确保每个判断/规划/行动/修正可回溯到客观证据或内部真实记录；审计记录完整、防篡改、可回溯；撤回/删除对象保留必要审计关系但不继续被禁用途。`[终局] L3280, L3282`。

## 2. 范围

- 覆盖必须可追溯的重要操作（§4）；审计记录关联责任域/对象/动作/来源证据/时间/版本/影响/结果。`[终局] L3280`。
- 审计 ≠ 不可抵赖合规替代；审计字段完整性与防篡改细节（G2）`[确认采纳]` 原则，实现细节 `[待用户拍板]`。`[终局] L3282`。
- **不做**: 不要求学生理解审计结构；不把审计当教育效果证明。

## 3. 责任

- 审计链由确定性设施承载（审计记录完整性代码强制，不靠 prompt）。`[终局] L3099`。
- 撤回/删除对象时保留必要审计关系但不继续在被禁用途下使用。`[终局] L3282, L2620`。

## 4. 必须可追溯的操作清单 `[终局] L3280`

证据进入/撤回/失效；判断候选裁决生效修正；规划生成变更暂停回退结束；任务生成执行检验反馈；资产准入确认修订撤回交接；自生长/自进化候选采用回滚；权限状态迁移高危操作；售后校准查看意见回流合并；错误传播隔离降级回滚。

## 5. 审计字段表（可落 schema）

| 字段 | 类型 | 说明 |
|---|---|---|
| `audit_id` | uuid | 唯一标识 |
| `operator` | string | 操作者/责任域 |
| `object_type` | enum（证据/判断/规划/任务/资产/权限/…） | 对象类型 |
| `object_id` | uuid | 对象标识 |
| `action` | enum（进入/撤回/裁决/生效/修正/…） | 动作 |
| `evidence_refs[]` | uuid[] | 来源证据（外部/内部） |
| `time` | timestamp | 时间 |
| `version` | string | 版本 |
| `impact_scope` | enum（任务/路径/规划/全局） | 影响范围 |
| `result` | string | 结果 |
| `hash` | string | 链式哈希（防篡改） |

关联：证据/判断/规划/任务/资产；`trace_info` 回溯源。`[终局] L3280, L1684`。

## 6. 防篡改要求（G2）

- 审计记录自身完整、防篡改、可回溯。`[终局] L3282`。
- **确定性实现示例**: 追加式 append-only 日志 + 链式哈希（每条 `hash = sha256(entry + prev_hash)`）+ 写后只读校验；缺失字段拒绝写入。实现细节与密钥管理 `[待拍板]`。
- 撤回/删除对象保留必要审计关系，但不继续在被禁止用途下使用。`[终局] L2620`。

## 7. 审计 vs 评测（机制/教育效果分开）`[终局] L3284`

- 机制/质量评测：判断是否基于证据/等级是否合理/规划可执行/Agent 越权/漂移——可用自动化指标/回归/模拟。
- 教育效果评测：学生是否受益/长期能力/成绩升学改善——须真实长期验证，不由机制评测冒充。
- 质量门槛是机制判据，如判断须有证据引用且强度不超范围、候选不静默生效、冲突不强行归纳、越权被阻断、错误不传播、未确认不升级。`[终局] L3286`。
- 通用评测工具可复用（Inspect AI/Ragas/Langfuse 等），但组件能力不证明教育有效。`[终局] L3288`。

## 8. 监察核验（与 `10-监管` 衔接）

监察核验证据使用（外部/内部混淆、判断引用实际证据、推断冒充事实、越权、降级到位）；监察不做判断，只把关"判断是否基于客观真实证据、是否合规"。`[终局] L4121`。

## 9. 完成定义

学业军师能对重要操作建立可追溯审计；能区分机制评测与教育效果评测；通过机制质量门槛，但不以机制评测冒充教育效果。`[终局] L3290`。

## 10. 验收标准（L1/L2 首版可验）`[终局] L3292-3299`

1. 证据/判断/规划/任务/资产/自生长/权限/售后校准/错误处理均可追溯；2. 审计记录关联责任域/来源/时间/版本/影响/结果；3. 审计完整可回溯、可撤回但保留必要关系；4. 机制与教育效果评测分开；5. 质量门槛是机制判据不冒充效果；6. 学生不承担审计理解负担；7. 通用评测工具可复用，教育效果不外推。L3 真实、L4 效果 `[待验证]`。

## 11. 实际证据 / 未验证边界

- **实际证据**: 审计可追溯/机制与效果测评分离/质量门槛 `[终局] Q7-5` 确认；审计记录完整性确定性强制 `[终局] Q7-1`。
- **未验证边界**: 审计字段表与防篡改实现细节（G2）`[待拍板]`；监管对未知错误/长期漂移检测 `[待验证]`。
