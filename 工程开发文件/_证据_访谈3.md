## T1 学生端产品本体职责与边界（产品层闭环中的核心定位）

- [用户明确判断] 阶段 1·问题 1-1（L397-401，上层建筑/经济基础）：受访者明确指出上一版把"学业规划"与证据、判断、Agent、教与授并列不妥，须区分上层建筑与底层组件。
  > "学业规划是一切执行的上层建筑，所谓教与授只是服务规划的手段；其他的是不可缺少的底层组件。"
  > "上层建筑 = 产品直接向学生承担的学业责任……经济基础 = 支撑这些责任成立的底层能力、数据、规则、运行设施和资源。"
- [确认采纳] 阶段 1·问题 1-1（L405-435，分层图与最核心不可缺少）：学业规划（上层建筑/最高责任）→ 判断引擎专项化 + 术业有专攻 Agent（认知结构）→ 证据/学业资产/自生长自进化（事实基础与长期演进）→ 状态/权限/会话/记忆/审计/回滚/技术栈/监管（经济基础）。
  > "学业规划至少承担 10 项责任：位置判断、目标确定、差距分析、路径设计、任务部署、资源安排、执行监测、结果检验、动态修正、阶段衔接。教与授不是学业军师的最高目的，而是服务学业规划……的手段。"
- [确认采纳] 阶段 1·问题 1-2（L456-476，规划不可下放的最终责任）：学业规划承担 10 项不可下放责任（全局位置/阶段目标/差距/路径/路径最终权威/任务资源全局安排/执行检验统一监测/动态修正裁决/阶段衔接/对学生的最终承诺）。判断引擎与专项 Agent 只能供判断候选与专业意见，不能各自定全局路径。
- [确认采纳] 阶段 1·问题 1-11（L891-910，成立边界）：学业军师成立需同时具备规划最高责任、判断引擎专项化、专项 Agent 服从统一规划、可追溯证据、进入任务/教与授/行动/检验、结果反馈修正、学业资产受控沉淀、自生长受控、低负担、确定性设施保护。
  > "设计成立不等于工程实现，工程实现也不自动等于教育效果成立。"（L910）
- [用户明确判断] 阶段 2·问题 2-5（L1195-1197，完整档案必建）：
  > "完整个人档案、全部学科信息、长篇目标问卷、复杂学习偏好配置这些可以有也必须有。这些内容都没有，以证据驱动的学业军师就是伪军师。"
  > "不能有的只包括关于 Agent 复杂操作的内容部分；关于学业的一切内容不算是复杂性转嫁。"
- [确认采纳] 阶段 2·问题 2-2（L1005-1078，第一性问题）：学生根本问题是建立"当前位置—阶段目标—差距及成因—路径—行动—检验—反馈—修正"可理解因果链，而非单次答题或一次计划生成。产品替学生承接高认知负担综合判断，不把学生变成系统管理员。
- [确认采纳] 阶段 13·Q13-5（L4632-4636，学生为唯一必要承接者）：以学生为现实材料唯一必要承接者，以学生带回的可核验客观实体材料和产品内真实行动/检验为主要现实依据。
  > "学业军师与外部现实的最低必要关系是学生把自己能够取得的真实客观学业材料带回产品，并结合产品内真实行动和检验结果完成判断、规划与修正。"（L4632）

## T2 客观证据模型（外部/内部证据）

- [用户明确判断] 阶段 3·问题 3-3（L1538-1546，证据两大类型不可模糊）：
  > "证据首先划分为两大类型，这一区分不可模糊：一是从学校带回来的外部证据；二是在学业军师产品内产生的内部证据。"
  > "1. 外部证据：从学校/现实带回的、独立于学业军师产品的证据……作业、试卷、错题、成绩、课程要求、测验结果等——由学生带回，源头在学校/现实；2. 内部证据：在学业军师产品内产生的证据……行动记录、任务完成情况、练习过程、检验结果、产品内形成的判断过程记录等。"
  - 不可模糊三因（L1549-1552）：来源权属不同；独立性与可靠性不同；引用责任不同（外部标"学校来源、经学生承接"、内部标"产品内产生"）。
- [确认采纳] 阶段 3·问题 3-3（L1559-1573，证据强度分级 + 证据>记忆>上下文）：强度分级——高=原始材料/可核验事实；中=学生陈述（作线索）/产品内真实行动记录；低/候选=学生转述/模型推断/临时上下文。三者关系"证据 > 记忆 > 上下文"；记忆不能静默成为证据；学业资产必须可回溯到证据。
- [用户明确判断] 阶段 3·问题 3-8（L1842-1845，证据驱动定位）：
  > "证据是学业军师的一大特色，学业军师是以客观真实证据驱动的产品。"
  > "证据不是判断引擎的一个可选输入，而是贯穿整个产品的驱动性事实基础。"
  - 三条承诺（L1859-1862）：实事求是；因地制宜；具体问题具体分析。
- [已被修正][用户明确判断] 阶段 13·Q13-2（L4618-4624，教师内容边界根级修正）：
  > "取消教师批注、评分、评语、意见、评价和学生转述教师意见作为学业军师产品输入、可信度分级对象或效果裁判。教师没有义务配合产品，也不为产品生产批注、评分、转述或校准内容。"
  > "当前外部证据只取学生带回的可核验客观实体材料……产品只使用这些材料中的具体事实；不继承教师主观解释。"
  - 历史表述在阶段 1/2/3/6/10/13 逐处标记 `[已被修正]`（L705、L1248、L1545、L1586、L2621、L4075、L4560、L4620）。
- [确认采纳] 阶段 6·问题 6-1（L2568，数据模型第一层根级区分）：外部证据+内部证据为数据模型第一层根级区分；产品判断不是证据本身；模型推断不是客观证据；外部/内部证据类型不能在后续处理时被静默转换。

## T3 状态与生命周期（候选/生效/暂停/回退/失效/撤回/删除，合法迁移）

- [确认采纳] 阶段 6·问题 6-3（L2676-2711，状态模型与合法迁移）：不同对象各有状态维度——证据/判断（事实/分析/推断/候选/未知/冲突）/规划（草案/候选/生效/暂停/回退/结束/失效）/任务/资产（候选/待确认/阶段内有效/待复核/失效/撤回/归档）/适配/权限。状态迁移必须经合法性检查（触发事件+证据/权限条件），模型只能提候选、不能绕过状态规则。
  > "模型不能把候选判断直接写成生效判断；任务生成不能直接等同于任务完成；学生点击不能自动证明充分理解；一次检验结果不能自动形成长期资产。"（L2692）
  > "高影响和根级状态不会由运行时自主改变。"（L2710）
- [确认采纳] 阶段 6·问题 6-2（L2619-2644，数据与证据生命周期）：不同对象应有不同生命周期；外部证据不能因学生提交就自动成为"学校已确认事实"；内部证据不能因产品产生就自动成为客观真实结论；证据撤回后受影响判断/规划/资产/适配须被识别并限制继续使用；任何对象不得无来源静默升级或继续传播。
- [确认采纳] 阶段 1·问题 1-10（L867-869，规划暂停/恢复/回退/结束/失效语义）：
  > "暂停=暂时不推进相关规划或任务但保留当前状态原因恢复条件，不等于完成也不等于失败；回退=将执行或规划恢复到上一稳定版本或生成基于旧状态新版本，不能假装抹除已发生行动影响；结束=……必须写明结束原因、达成/未达成状态、形成学业资产候选……"
  > "失效不是删除，系统标记失效原因、保留历史版本、停止沿用……"（L869）
- [确认采纳] 阶段 11·问题 11-2（L4244-4258，学业资产完整生命周期）：候选 → 待确认 → 当前有效 → 待复核 → 修订/降级/撤回/失效/封存/删除；撤回用途≠删除审计；删除后不得被禁止用途继续使用；每次转换保留来源、原因、范围、状态、影响。
- [确认采纳] 阶段 4·问题 4-6（L2140-2143，状态转换显式化）：任何从一种对象转入另一种对象都必须是显式、可追溯的状态转换，不能静默发生（临时上下文→候选认识→受控记忆/阶段性认识→学业资产→新判断规划）。

## T4 权限与确定性强制（代码强制，不靠提示词）

- [确认采纳] 阶段 7·问题 7-1（L3097-3125，确定性设施强制）：
  > "学业军师的高影响、权限、证据和义务边界，必须由确定性的底层设施强制，而不是靠提示词约束模型……必须由代码、数据、权限和审计强制，不能交给 Agent 自律。"
  > "确定性优先：凡能用代码、数据、权限强制的，不依赖模型或提示词。"（L3102）
  - 至少强制项（L3099）：身份角色数据隔离、输入来源与授权登记、状态迁移合法性、证据状态/来源字段完整性、高影响或不可逆操作拦截、未确认内容不得升级、Agent 不得改写根级规则、自生长不得绕过批准、审计完整性、撤回删除过期访问控制、工具/插件/外部服务调用边界、停止暂停回退灾备条件。
- [确认采纳] 阶段 1·问题 1-3（L514，判断引擎 vs 确定性设施分工）：
  > "必须由确定性设施强制：身份角色权限、学生教师机构家长数据隔离、输入来源和授权登记、状态迁移合法性、证据状态和来源字段完整性、高影响或不可逆操作拦截、未确认内容不得升级为生效规划或长期资产……"
  > "判断引擎负责形成受约束的认知输出；确定性设施负责决定该输出是否有资格生效、能否执行以及能否写入长期状态。"
- [确认采纳] 阶段 6·问题 6-4（L2761-2765，四维权限）：权限按"主体身份 × 角色 × 对象范围 × 操作类型"控制；操作类型区分查看/提交/分析/建议/写入候选/确认/修改/撤回/删除/发布生效/暂停/回滚；"可查看≠可修改，可建议≠可生效"。学生无权修改根级权限规则，Agent 无权替学生完成重大确认。
- [确认采纳] 阶段 7·问题 7-2（L3162，编排确定性控制）：
  > "编排本身由确定性底层设施约束：谁在何时可调用谁、读什么、写什么、交接是否合法、是否越权，均由底层设施校验，不靠 Agent 自觉。"

## T5 多代理编排（总军师/学科军师/专项/横向域；调度/交接/冲突）

- [用户明确判断] 阶段 6·问题 6-4（L2730，全局—局部 Agent 体系）：
  > "依据客观事实，学业是多学科的集合，就存在全局与局部的区分。全局指的是全学科（完整学业），局部指的是单一学科及其下属的各个内容。学业军师必须就是一个总军师（全学科/完整学业）+ 单一学科军师 + 专项 agent + 其他各个部门的 agent。将学业比作战场更能直观呈现这个关系。"
- [确认采纳] 阶段 6·问题 6-4（L2738-2769，分层与协作）：总军师（全局目标/优先级/跨学科协调/统一表达）→ 单一学科军师（学科整体位置与路径/学科内目标差距任务/协调学科专项）→ 责任部门 Agent（证据/判断/教与授/反馈与检验/学业资产/监管）+ 学科专项 Agent。局部结果可影响全局但不能自动改写全局；总军师必须评估影响范围；全局规划不能凭空压过局部事实。冲突意见不得静默择一；只有规划层能把候选路径变成生效规划。
- [确认采纳] 阶段 7·问题 7-2（L3138-3163，编排/协作/交接）：编排原则——统一入口、总军师统筹、学科军师局部、横向责任域跨学科支撑、证据状态共享、候选不生效。交接时保留：来源、学生、学科、责任域、证据、版本、影响范围、待决事项、完成状态。
  > "重大冲突暂停相关规划变更并请求裁决（规划层/必要时人工）；局部优化不得突破全局规划目标。"（L3160）
- [确认采纳] 阶段 1·问题 1-4（L540-578，术业专攻 Agent 体系）：以学业规划为唯一全局责任，以判断引擎为统一认知约束，按责任域与学科两个正交维度组织；专项 Agent 有统一契约，不直接面对学生（学生只面对统一入口）；缺少合格专项 Agent 时诚实降级、不伪装专业结论。

## T6 证据/审计链（可回溯/防篡改）

- [确认采纳] 阶段 7·问题 7-5（L3280-3298，审计可追溯/防篡改）：
  > "审计记录应关联：操作者/责任域、对象、动作、来源证据、时间、版本、影响范围、结果。"
  > "审计是记录与追溯，不是不可抵赖的合规替代……审计记录自身须完整、防篡改、可回溯；学生不需要理解审计结构；撤回/删除对象时，保留必要审计关系但不继续在被禁用途下使用。"（L3282）
  - 可追溯操作至少包括：证据进入/撤回/失效；判断候选/裁决/生效/修正；规划生成/变更/暂停/回退/结束；任务生成/执行/检验/反馈；学业资产准入/确认/修订/撤回/交接；自生长候选/采用/回滚；权限/状态迁移/高危操作；售后校准查看/意见/回流/合并；错误传播/隔离/降级/回滚。
- [确认采纳] 阶段 9·问题 9-4（L3936，闭环端到端可回溯判据）：
  > "从真实输入起，能沿'证据→判断→规划→任务→教与授→行动→检验→反馈→修正→资产'读完一整圈，每环可回溯到上一步……任一步缺失或无法回溯，则未闭合。"（L3936）
- [确认采纳] 阶段 3·问题 3-8（L1866，监察核验证据维度）：监察核验判断依据——用了哪些证据、是否有伪证、是否把无证据当事实、是否越权使用证据；监察不做判断，只把关"判断是否基于客观真实证据、是否合规"。
- [确认采纳] 阶段 10·问题 10-6（L4118-4126，无据当事实的监管实现）：证据字段完整性由底层设施强制；监察做语义层核验（是否真的依据证据），发现伪证/越权/漂移即阻断、降级、回滚。
- [确认采纳] 阶段 9·问题 9-4（L3954，五条落地验收）：单一证据主链全链可回溯；回流-修正；反向验证（演示"看着像闭合实未合"失败例）；层标记（L1/L2/L3/L4）；未闭合显式标记（交付界面标 [未闭合]）。

## T7 业务回滚语义

- [确认采纳] 阶段 7·问题 7-7（L3370，业务级回滚产品层定义）：
  > "错误判断、规划、资产、自生长、状态迁移可回滚到上一稳定版本；回滚保留历史关系，不假装抹除已发生动作；业务级回滚须产品层定义（方向 5 已确认组件无内建业务回滚）；不可逆操作在执行前被拦截，而非事后回滚。"
- [确认采纳] 阶段 5·问题 5-2（L2337，业务回滚不可外包）：无论采用哪个外部项目，业务级状态、错误传播阻断和回滚语义必须由学业军师自持。
- [确认采纳] 阶段 5·问题 5-3（L2378，运行可靠性门禁含业务回滚）：候选能力须在目标环境验证"异常撤回和业务级回滚"；"代码存在或文档宣称支持"不能替代运行验证。
- [确认采纳] 阶段 1·问题 1-10（L867，回退不假装抹除）：承接 T3，"回退=将执行或规划恢复到上一稳定版本或生成基于旧状态新版本，不能假装抹除已发生行动影响"。
- [确认采纳] 阶段 9·问题 9-2（L3862-3863，Harness+监管含回滚）：Harness+基础监管必建，错误阻断/不可逆拦截/审计/回滚由确定性设施承载，首版用故障注入验证可回滚。

## T8 0.5→1 路径与候选（复用改造＞重构＞自建；开源组件候选与准入）

- [确认采纳] 阶段 4·问题 4-4（L2053-2059，0.5→1 复用顺序 + 责任自持）：
  > "0.5→1 的路径应为：复用 → 改造 → 受控整合 → 必要重构 → 最后自建。"
  > "学业军师必须拥有 Harness 责任"与"学业军师必须从零编写 Harness"是两件不同的事。责任自持，实现可以复用。"（L2053）
  > "不能直接把组件拼起来：直接复用多个 Agent 框架，可能形成'能运行但不构成学业军师'的系统。"（L2057）
  - 稳定性至少四层（L2059）：组件稳定性、组合稳定性、责任稳定性、长期运行稳定性；外部组件往往只能帮第一层、部分第二层，第三四层须学业军师自证。
- [确认采纳] 阶段 1·问题 1-8（L733，复用顺序 + 自持内容）：先确定本体，再按"复用 → 改造 → 受控整合 → 必要重构 → 最后自建"选实现方式；自持=定义权/控制权/最终责任/替换权在学业军师一方（不等于从零编写）。外部底座不能反向决定产品本体。
- [确认采纳] 阶段 5·问题 5-1（L2279-2283，DeepTutor 定位）：
  > "DeepTutor 应定位为学业军师的候选工程底座与能力来源，而不是学业军师产品本体，也不是已确认采用的首版底座。"
  - 不能反向决定：学业规划是否最高责任、判断引擎定义边界、外部/内部证据规则、学业资产生命周期、学生控制、一主多专、监管监察、自生长自进化范围、首版完成定义。
- [确认采纳] 阶段 5·问题 5-2（L2308-2341，能力单元拆分 + 六种处理）：外部项目须拆成能力单元单独审查；六种处理=直接复用/改造适配/受控整合/隔离使用/暂缓放弃/必要自建。12 项准入检查。
- [确认采纳] 阶段 5·问题 5-3（L2370-2386，五类门禁 + 三态区分）：候选研究对象 ≠ 可复用能力 ≠ 首版实现组成；须依次过产品责任、能力适配、运行可靠性、安全治理、替换退出五类门禁。DeepTutor 当前只达"优先评估候选"，未通过产品集成验收。
  > "单 Agent loop 与学业军师'一主多专'之间存在适配缺口；……当前不能表述为'已采用 DeepTutor'。"（L2386）
- [确认采纳] 阶段 5·问题 5-5（L2466-2474，首版取舍）：首版不以外部组件接入数量为完成标准，而以产品责任形成稳定闭环为准；12 项首版进入条件；"不应进入首版"情形列举；DeepTutor 暂不直接作为整体首版底座。
- [确认采纳] 阶段 5·问题 5-4（L2417-2437，反事实本体测试）：产品本体与实现底座分离；"如果删除 DeepTutor、OpenClaw、Hermes……学业军师是否仍然成立？如果答案是肯定的，说明底座未反向定义产品本体。"

## T10 范围与边界（学生端/B端/云端/后端闭环；工程文件处理；本地化单实例；学生唯一承接者）

**层次一：产品层三端闭环（来源确认）**
- [确认采纳] 阶段 8·问题 8-3（L3529-3546，三端部署结构）：学生端 PC/平板（本地权威数据+Agent 运行+判断引擎/Harness/监管+总军师+学科军师+专项+横向责任域）→ 云端服务（模型 API 网关+售后服务）→ B 端教师 Web 工作台（PC 浏览器，非技术）。云端不成为学生学业数据唯一权威；B 端教师工作台不直接向学生端发送临时 Agent 指令。
- [确认采纳] 阶段 8·问题 8-4（L3568，产品链开发路径）：
  > "基本路径是学生端本体 → 云端售后 → B 端教师工作台 → 闭环整合。"
  - 第1步学生端本体（单学生/单学科/单任务最小闭环）→ 第2步云端售后服务 → 第3步B端教师工作台 → 第4步闭环整合（L3573-3579）。
- [确认采纳] 阶段 8·问题 8-7（L3676-3683，三端工程责任与开发顺序）：学生端运行学生专属 Agent/保存本地权威数据/调用云端模型 API；云端负责模型 API/必要数据接收/鉴权/售后校准记录/同步/审计/机构服务；B 端教师 Web 负责授权范围内周期性人工校准；私域下载官网负责设备识别/版本分发/授权入口。最小端到端验证对象（L3680）：一个机构+一个教师售后账号+一个学生+一个学科+一项真实学业问题+一份外部证据+一条内部行动记录+一次云端模型调用+一次教师周期校准+一次校准回流+一次本地重新规划。
- [确认采纳] 阶段 8·问题 8-5（L3602，私域交付）：学业军师是面向机构和私立学校的私域产品，官方提供下载/访问入口；学生端按设备和 OS 提供独立交付版本：PC 版（macOS、Windows）和平板版（iPadOS、Android）；B 端教师用 PC 浏览器 Web 工作台；不以公共应用商店和个人购买为默认前提。iPadOS 官网直装受 Apple 分发规则限制（L3621）。
