## 一、回应 product 报告

### P-1：B 端定位与学生端本体统一表述

- **判断：认同（补充工程边界）**。
- **对方条目**：`_批判_product.md` P-1，主张统一「机构购买、学生被服务、学生设备承载」三元表述。
- **一手定位**：`_证据包.md` T10，`[访2] 1-2 L280-287`（机构是客户与赋能关系，学生是直接作用对象）；`[访3] 6-8 L2990`（一个 Agent 产品只能服务一个人）；`工程开发文件/CLAUDE.md L37-39`（工程文件只落实学生端本体）。

- **架构回应**：同意须写清「商务客户/授权来源」与「学生端运行主体」不是同一角色；但不应因此在学生端首版扩写机构端角色、账号或分发实现。工程上先定义学生端的授权输入边界，机构端实现留在闭环提及层。

### P-2：云端模型 API 网关与云端不纳入的张力

- **判断：认同，且列为架构硬边界澄清项**。
- **对方条目**：`_批判_product.md` P-2，主张学生端应可写模型调用接口契约，而非云端网关实现。
- **一手定位**：`_证据包.md` T10，`[访3] 9-1 L3801-3814`（云端模型 API 网关列为学生端系统前提）；`[访3] 8-5 L3606-3619`（云端统一代理模型 API，客户端不持 API Key）；`工程开发文件/CLAUDE.md L37-39`（云端/B 端/后端仅提及）。
- **状态**：两项边界均为 `[确认采纳]`/`[用户明确判断]`；接口分界为 `[推断]`，须成文。
- **架构回应**：认同 P-2。应把「学生端模型调用端口、请求/响应契约、失败/超时/脱敏/不可用语义」纳入学生端规范；不纳入网关部署、供应商实现和云端数据权威。该边界是本地权威数据与云端仅模型 API原则的工程化表达，不是把云端后端偷渡进来。

### P-3：单实例与机构多学生分发

- **判断：认同，但反驳其作为当前学生端架构必改项**。
- **对方条目**：`_批判_product.md` P-3，主张机构在首版学生端角色待拍板。

### P-4：资产是否第三类证据

- **判断：认同且补充为数据模型硬约束**。

### P-5：教师售后校准回流与取消教师主观输入

- **判断：部分认同，反驳「应预留教师回流作为学生端证据语义位」的强表述；先分层、再决定**。
- **对方条目**：`_批判_product.md` P-5，主张先裁决「教师售后校准回流≠已取消教师主观输入」，并在学生端证据模型预留回流位。

- **架构回应**：认同这是冲突，但不能未经用户拍板断言「回流不属于教师主观输入」。`L3037`只证明未来存在结构化回流、本地校验和本地最终权，不证明回流可成为学生端事实、资产或效果裁判。架构最低安全处理是：首版学生端禁止教师意见进入证据/判断；后置回流先作为带来源、授权、版本、候选状态的外部输入申请，不能升级为事实/资产，直到产品层明确其地位。故 P-5 的「先裁决」认同，「直接预留为证据位」质疑。

## 三、汇总结论

### 我认同的

1. 两报告关于 G1/G2/G3/G7、唯一状态源、候选与生效分离、教师终局修正、云端模型 API 接口边界、最小闭环与 L1/L2 术语冲突的核心判断。
2. product P-5 与 risk C2/D-3 等高风险项确实是工程前置缺口；但 P-5 的最终回流语义不能由架构代理替产品裁决。
3. risk G11 对首版样例的阻塞判断成立；其对所有架构规范均必须等 G11 的强阻塞范围需收窄。

### 我不认同的

1. 不认同未经拍板就把教师售后校准回流定义为可预留的「证据语义位」：`[访3] 13·Q13-2 L4618-4624` 明确排除教师主观输入，`[访3] 6-9 L3037-3039` 只确认结构化回流、本地校验和本地最终权，尚未确认其事实/资产地位。
2. 不认同 G11 未定就阻塞全部工程规范：`[访2] 3-2 L2467-2830` 的责任域、交接包、受控调用和 `[访3] 7-7 L3370` 的回滚原则具有对象无关部分；应先写契约模板，再以 G11 实例化验收。
3. 不认同仅靠词检作为教师边界的充分防护；对象来源、用途、状态和权限必须由确定性设施校验。

### 我要追加质疑的

1. **教师回流的身份必须先定**：它究竟是禁止进入学生端的后置运维事件、仅供校验的外部材料，还是可提出候选但永不得直接生效的输入？在用户拍板前，学生端架构只能实现前两项的安全下界，不能预设第三项。
2. **最小闭环的架构模板与首版对象如何解耦**：若工作文件把学段/学科/任务绑定进状态机和权限模型，G11 会反复返工；若完全抽象，又无法通过 L1/L2。需要辩论组确定「对象无关契约 + 单一实例化样例」的分层验收方式。
