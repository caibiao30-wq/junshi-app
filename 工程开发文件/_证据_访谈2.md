## T1 学生端产品本体职责与边界

- [确认采纳] 问题 1-1（L23-37，最小完整因果链）：产品承担的最小因果链，是"让学业判断能够进入真实行动，并让真实结果能够反过来修正学业判断"。
  > "学业军师不应只对'回答问题'或'生成规划'负责，而应对以下**最小完整因果链**承担产品责任：基于可追溯的学业信息理解学生处境 → 形成受约束的判断 → 组织规划与下一步行动 → 提供必要的教与授支持 → 要求行动产生可观察结果 → 接收现实反馈 → 修正后续判断。"
  > "产品责任既不能扩大为'替学生完成学业'，也不能缩小为'提供学习建议'。"

- [确认采纳] 问题 1-1（L43-54，十项责任分类表）：产品责任分为核心责任（判断、规划、转化任务、教与授、促成真实行动、跨学科协调）与必要支撑（识别整理信息、学校反馈、沉淀资产、证据/会话/记忆/监察治理）。表内"不属于产品责任"（L129-138）：替学生完成作业考试、保证升学结果、把规划界面当真实行动完成、代替学校教师家长、扩到商业变现法律责任。

- [确认采纳] 问题 1-2（L280，产品定位）：
  > "**学业军师是一款面向中小学教育相关机构的 B 端学业支持产品，直接作用于学生真实的阶段性学业过程。**它面向学生全学科的整体学业协调，以学生持续产生的学习证据和学校现实反馈为主要判断依据……产品以一套覆盖不同学业阶段的统一产品结构承载上述核心关系，再通过学业阶段配置、学科内容和专业能力适配小学、初中、高中等不同教育阶段；产品提供方为相关教育机构提供技术与服务赋能，但不直接参与实体教育业务经营。"

- [确认采纳] 问题 1-2（L282-287，四个限定）：①B 端是客户与赋能关系（学生是产品直接作用对象，机构不等于产品本体）；②阶段性学业是时间边界（阶段间明确交接，不静默延续）；③跨学段适配是结构属性、非已验证事实（[待验证]）；④产品本体不替机构经营实体教育业务。

- [确认采纳] 问题 1-5（L575-733，产品本体结构）：正式采用"**六个核心业务责任域 + 四项横向控制机制 + 两项产品结构能力**"取代原"十一项平行能力"：
  - 六责任域：全学科学业理解与整体协调；学业证据治理与判断基础；学业路径与任务推进；教与授/行动与检验闭环；学校现实反馈与阶段性验证；学业资产与阶段内持续认识。
  - 四横向机制：学生主体与责任边界；会话与责任域治理；监察/质量门槛/回滚；证据、状态与权限统一控制。
  - 两结构能力：跨学段统一产品结构；B 端机构接入与角色协作。
  - L733："这十二项不是十二个必须分别开发的 Agent，也不是十二个页面功能，而是学业军师产品本体需要定义和控制的责任域、治理机制与结构能力。"（其中分类是否作为当前能力清单仍 [待确认]）

- [确认采纳] 问题 1-1（L144-167，学业军师与学生分界）：学生保留目标/重大方向确认权、事实纠正权、建议接受/拒绝/暂停/调整权、实际行动责任与最终参与责任。未决边界：军师日常指挥权与学生强制确认情形的具体边界（[待确认]）。

## T2 客观证据模型（外部/内部证据）

- [确认采纳] 问题 1-8（L1101，核心结论）：
  > "学业军师不能把所有输入都当成同一种'数据'，也不能把所有进入系统的文字都直接当成证据。任何输入都必须先经过对象识别、来源登记、用途限定和状态归属，才能决定它可以支持什么判断。"
  > "输入的存在不等于事实成立，事实成立不等于能力形成，学生授权处理也不等于授权其进入资产、记忆或对外传播。"

- [确认采纳] 问题 1-8（L1121-1163，五类输入的产品定义与证据地位）：
  1. 学业材料本体（作业/试卷/错题/练习/教材/教师批注）→ 先为"材料对象"，完成来源归属登记后才可能成为证据；单份材料不能直接证明长期水平/能力形成。
  2. 学生补充说明与主观处境 → 保留为学生自述/意图/线索，不能自动获得与学校结果相同证据强度。
  3. 学生实际行动记录 → 状态链区分布置/知情/接受拒绝暂停/执行/报告完成/收到材料/待检验/已检验。
  4. 学校或教师反馈 → 重要外部反馈/验证材料，单次反馈不能证明稳定能力或产品因果效果。
  5. Agent 分析与判断 → 默认性质是候选分析/候选判断，不是原始证据或正式事实。
  - L1202（专业结论）："材料本体、学生自述、实际行动、学校反馈和 Agent 判断具有不同证据地位；输入地位决定判断强度与允许产生的状态。"

- [确认采纳] 问题 1-9（L1252-1268，双维状态模型——外部/内部证据分离的关键）：
  > "'学生确认'和'现实复验'解决不同问题，不能合并成一个置信度。"
  - 内容状态链：信息提取 → 候选解释 → 待核实判断 → 有限范围工作判断 → 阶段内规划判断 → 学业资产候选 → 学生确认的阶段内认识。
  - 现实验证状态链：未验证 → 内部行动结果 → 有限外部反馈 → 连续现实反馈支持 → 现实反馈冲突 → 待复核/修订 → 失效或归档。
  - 同一条目"学生已确认但尚未现实复验""现实支持但学生未接受"都成立 → 外部证据（学校现实）与内部证据（学生确认）必须分离、不能互相替代。

- [确认采纳] 问题 1-5（L587-597，证据治理责任域）：证据不是普通输入，而是判断基础设施；"材料是什么→来源→能支持什么→不能支持什么→确定性→如何验证修正撤回"；L597"证据优先不能仅作为一句原则；必须最终落实为可执行的数据结构、权限和状态规则"。

- [确认采纳] 问题 3-4（L3300-3330，转换原则）：原始材料登记后才成为证据；证据支持判断但不自动变事实；"不存在'只要进入系统就自动变成记忆和资产'的转换"。

- [确认采纳] 问题 1-6（L785）："证据充分才允许有限范围诊断；证据不足须待核实并请求补充；证据冲突须展示而非强行归纳；无证据不得形成高确定性结论。"（区分外部反馈、学生自述、内部练习、Agent 推断，不得自动同类化）

## T3 状态与生命周期（候选/生效/暂停/回退/失效/撤回/删除，合法迁移，候选与生效分离）

- [确认采纳] 问题 1-6（L789，资产状态链——候选与生效分离）：
  > "以资产为例，状态可包括：候选→待学生理解→待学生确认→阶段内有效→待复核→修订版有效→失效→归档。底层负责定义合法状态、迁移条件、执行者权限、非法迁移拦截、变更历史、撤回、失效和回滚。Agent 可识别变化、提出迁移申请和解释理由，但不能自行宣布确认、完成、长期记忆或学校结果成立。"
  （L937 问题 1-7 相同链，"最终状态机仍待确认"[待确认]）

- [确认采纳] 问题 1-10（L1346-1354，状态迁移四类触发机制）：①Agent 发起候选迁移（携带目标对象/当前状态/建议目标/依据/来源/影响/所需确认者；"不存在'Agent 自己判断并直接完成高影响迁移'的正常路径"）；②底层规则自动触发的保护性迁移（缺身份→标不完整、证据撤回→下游标受影响、阶段结束→封存等，须保留审计、不得静默绕过学生主体）；③学生确认触发的迁移（重大方向/资产/记忆/传播/阶段交接必须学生明确可追溯确认）；④现实反馈/后续检验触发的迁移（不自动升级为"已确认的学生认识"）。

- [确认采纳] 问题 1-10（L1356-1373，确认不是统一状态）：十类确认各有独立对象与后果（材料归属/处理授权/分析理解/任务接受/规划接受/资产/记忆授权/传播/方向调整/撤回删除），每类"不代表什么"明确区分。L1366："资产确认……不代表能力已形成或永远有效"。

- [确认采纳] 问题 1-10（L1375-1383，无确认默认规则）：
  > "没有明确确认，不升级、不传播、不视为完成、不写入需要确认的长期状态。这条规则必须由底层默认执行，而非依赖 Agent 提醒自己。"
  - L1383："学生拒绝不是'确认失败'，而是具有独立语义的状态。"

- [确认采纳] 问题 1-9（L1296）：除低风险、可逆的临时分析外，正式事实/学生已完成/学生已掌握/重大规划/学业资产/阶段内记忆/对外传播/学生稳定能力/教育效果，都不得仅凭 Agent 判断升级。

- [确认采纳] 问题 3-4（L3411-3422，记忆生命周期链）：记忆候选 → 待确认 → 阶段内有效 → 待复核 → 修订版有效 → 降级 → 失效 → 封存/归档/删除；阶段结束时记忆默认不能自动进入下一阶段。

- [确认采纳] 问题 1-7（L939）："需学生确认的状态不能由 Agent 代确认；沉默不能升级为同意；系统生成不能升级为学生行动；内部练习不能升级为学校结果；资产不能从原始材料直接跳转生成。"

## T4 权限与确定性强制（代码强制，不靠提示词）

- [确认采纳] 问题 1-6（L813，核心强制原则）：
  > "底层必须阻断无来源高确定性判断、把自述当客观事实、把 Agent 推断当证据、未经确认写入资产、把内部练习写成学校结果、把沉默当确认、未授权跨域读取、越权修改和缺证扩大长期规划。**提示词只能指导行为，不能替代确定性规则；不可被单次模型行为突破的规则必须由底层代码、数据、权限和审计强制。**"

- [确认采纳] 问题 1-6（L750-773，分层结构）："确定性基础设施 + 受约束 Agent 管理层"上下位结构；L773"底层不是 Agent 的提示词后台，Agent 也不是底层规则的制定者"。

- [确认采纳] 问题 1-6（L867-869，Agent 明确不得承担的权限）：不得自行定义证据、把推断写成事实、确认学生意愿、写入正式资产/阶段记忆、改变阶段规划、修改权限、扩大读取范围、对外传播、删除审计、绕过监察、自我批准高影响输出。Agent 只能发起申请/提候选/解释理由，底层决定是否合法。

- [确认采纳] 问题 1-7（L907）：模块归属标准是"对象含义不混淆、来源和事实不篡改、权限不越权、状态迁移合法、高影响动作不静默发生、过程可追溯、错误可阻断/修正/回滚，以及 Agent 只能在授权范围工作"。

- [确认采纳] 问题 1-9（L1228）："Agent 输出不能直接等同于产品事实或产品状态……表达层、判断层、状态层应分开：Agent 可以生成表达和判断，但不能直接决定状态层的最终变化。"

- [确认采纳] 问题 3-1（L2139）："Agent 的所有读写都必须经过底层设施定义的接口；接口强制校验对象、来源、权限、状态、证据、影响和审计。Agent 不能通过非结构化文本或自行访问绕过接口。"L2183："读取范围由底层权限模型决定，不依赖 Agent 的提示词自律。"

## T5 多代理编排（总军师/学科军师/专项/横向域；调度/优先级/交接/冲突裁决）

- [确认采纳] 问题 3-2（L2444，核心结论）：
  > "学业军师不应采用'多个 Agent 自由对话、最后由一个 Agent 总结'的协作方式，而应采用：责任域隔离、底层统一约束、主军师统一编排、专业 Agent 分工执行、所有交接可追溯的受控协作结构。"
  - L2465："主军师是产品责任上的顶层协调者，不是拥有无限权限的超级 Agent。"

- [确认采纳] 问题 3-2（L2467-2512，责任域 vs 会话）：责任域回答"谁对哪类工作负责、能读什么、能输出什么、不能越哪些边界"，是产品与权限边界，由底层确定性设施定义强制；候选责任域含全学科协调/学科协调/证据治理/任务部署/教与授/学业资产/监察审计。会话回答"某项工作在什么范围开始/持续/暂停/结束/恢复"，绑定责任域/阶段/目标/可读可写对象/交接出口/审计标识；"一个责任域可产生多个会话；一个会话不能随意跨多个责任域；会话不是无限上下文"。

- [确认采纳] 问题 3-2（L2540-2570，责任域交接）：通过"结构化交接包"协作，至少含来源/接收责任域/目标/输入对象 ID/证据及来源/判断与状态/确定性/未知冲突/建议动作/允许与禁止执行范围/版本/审计标识。L2570："接收方不得把交接包中的'候选判断'当成'已确认事实'。"

- [确认采纳] 问题 3-2（L2572-2605，主军师职责与禁项）：主军师负责理解整体目标、决定调用哪些责任域、分发任务、汇总比较、识别跨学科冲突、请求补证复核、形成整体安排候选、向学生解释、把高影响变化提交底层确认。禁项（L2593-2604）：不得绕过证据设施读全部材料、自行改变对象类型、确认学生意愿、把候选规划直接写成正式规划、把学科 Agent 判断改写为事实、跳过监察审计、自我授权、以"整体最优"覆盖学生重大方向确认权。L2605："主军师是最高层协调责任者，但不是底层权限的最高豁免者。"

- [确认采纳] 问题 3-2（L2607-2622，专业 Agent 分工表）：学科 Agent（学科诊断/教与授/练习/检验，无权改全局优先级）、证据 Agent、任务部署 Agent、教与授 Agent、资产 Agent、监察 Agent、阶段管理 Agent、主军师。L2622："职责边界应由输入、输出、状态、权限和后果定义，而不是只由人格名称定义。"

- [确认采纳] 问题 3-2（L2624-2646，Agent 是否可直接调用）：原则上不允许任意自由调用；允许底层注册、责任域明确、输入输出预定义、带目标来源权限、结果记录、可控失败超时重试的受控调用；不允许自然语言随意发现调用、共享全部会话上下文、直接改他域状态、Agent 间口头确认代替学生确认、借中间链绕过权限、同一 Agent 同时拥有请求/批准/审计同一高影响操作全权。

- [确认采纳] 问题 3-2（L2735-2767，防碎片化）：底层统一对象/证据/权限/会话责任域/交接格式/状态机/审计/监察回滚/调用注册/输入输出契约；主军师统一目标、分配任务、比较、调序、处理冲突；专业 Agent 不跨域、不自扩输入、不改他域状态、不把局部判断包装成全局结论。

- [确认采纳] 问题 1-1（L198-207）：专业 Agent 输出必须受统一证据规则/权限规则/会话边界/状态标注/交接协议/失败暂停回滚机制约束；"Agent 数量或人格名称不构成产品责任本身"。

## T7 业务回滚语义

- [确认采纳] 问题 3-6（L4009-4083，回滚与恢复全流程）：
  - 需回滚的错误（L4011-4019）：非法状态迁移/越权污染/伪证或错误证据进入判断/未经确认的重大变更/错误写入资产记忆/传播交接错误/状态一致性破坏。
  - 回滚范围（L4021-4034）：判断/任务/规划/资产/阶段内记忆/对外传播/责任交接/学生可见控制状态；"回滚范围应与错误影响范围一致，不能过度回滚，也不能只回滚表面状态而遗留下游错误"。
  - 发起与批准（L4036-4043）：底层自动、监察提出申请、学生/机构要求、运维/人工受控介入；"关键的回滚应记录发起者、理由和批准路径，不能由同一 Agent 单方面判定'我错了并已回滚'"。
  - 快照（L4045-4055）：回滚前保留快照和版本以便回溯/比较/恢复/审计/防重复错误。
  - 下游引用（L4057-4065）：识别下游、阻断修正、不让错误继续传播、更新版本状态。
  - 学生知情（L4067-4069）：影响重大状态/资产/记忆/规划/传播的回滚应让学生知情并看到原因。
  - 防再传播（L4071-4079）：标记已修正/失效、阻断旧版本引用、更新下游、审计留完整过程。
  - 审计（L4081-4083）：回滚全过程（触发/范围/快照/下游/执行者/时间）都审计，不能只记"已回滚"。

- [确认采纳] 问题 3-1（L2325-2337，回滚如何执行）：定位受影响对象和下游、保留原版本、撤销/修正非法或错误迁移、更新受影响下游引用、记录回滚原因执行者时间、必要学生知情、避免半更新状态。L2337："Agent 可以建议回滚，但回滚的一致性和审计由底层负责。"

- [确认采纳] 问题 1-6（L811-813）：质量门槛/阻断/回滚属底层硬性要求，确定性强制。

- [待验证] 回滚能否正确处理错误传播（L4154）；具体回滚批准路径与通过门槛 [待确认]（L4153）。

## T8 0.5→1 路径与候选（复用改造＞重构＞自建；开源组件候选与准入）

- [确认采纳] 问题 3-8（L4354-4369，0.5→1 准确含义）：
