# 学业军师 0.5→1 候选组件名单（学生端能力域）

> **性质**：候选联网研究结果，前置资源，供下一轮 teams 评估。全部条目统一 **`[候选/待验证]`** —— **候选≠采用**，不充当底座、不含门禁预筛/产品责任/安全评级/是否纳入首版判断。
> **能力域**：按 `_证据包.md` 既定能力域分组，仅覆盖**学生端产品本体**相关域；云端/B端/后端能力域不在本名单（留待对应阶段）。
> **取证时间**：2026-09-15。来源/许可证/版本/取证时间=已核事实；对学业军师的适用=推断（单独标注）。
> **来源**：合并 5 份研究草稿（`_候选草稿_审计编排` / `_候选草稿_确定性强制状态机` / `_候选草稿_数据检索` / `_候选草稿_运行时测评` / `_候选草稿_底座`），跨组重复项去重标「另见」。

## 结论摘要

- 共 **60+ 候选条目**，全部 `[候选/待验证]`，覆盖 6 大能力域（确定性权限强制、状态机、审计链、多代理编排、本地数据与检索、运行时与测评）。
- **两处许可风险需下一轮门禁专项核验**：① `dify`=修改版 Apache-2.0（带商业授权前置条件）；② `EventStoreDB`=Kurrent License v1（非 OSI 开源，限制托管服务）。
- **维护状态警示**：spring-statemachine、LlamaIndexTS、electric-sql/typescript-client 已 archived；XState 最新 tag 为 alpha 预发布。
- **环境阻塞（如实）**：Jina Reader/WebFetch 通道被安全策略屏蔽，唯一可用联网一手通道为 GitHub MCP；成员均降级到一手来源，证据等级未降。

---

> **候选边界标记**：条目只说明可借鉴的机制，不承载产品语义、产品责任或最终裁决；是否可嵌入学生端仍须按本地承载、许可证、版本、维护状态与集成验收核验，并保留替换/退出路径。纯云端、服务端或分布式组件统一视为**机制借鉴/闭环提及**，不列为可嵌入学生端候选；其条目不得被解读为采用栈。
