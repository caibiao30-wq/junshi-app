# 判断引擎细则（认知层）

> **inherits_from**: `JUNSHI-ENG-MASTER-001`
> **版本**: v1.0 · **2026-09-15** · **地位**: 不可替换自持核心 · **母源**: 工程开发总文件 §5.1/§1
> **权威锚**: `[终局]` = `访谈资料/学业军师终局访谈/02_访谈记录.md`（阶段 3 全体）

## 1. 目的

把通用 LLM 限定为只适配学业军师的专项判断能力：以 LLM 通用理解/推理为基础，通过学业对象限定、证据约束、判断流程、输出契约、降级规则和范围边界，收敛为服务学业规划的专项认知增强层。`[终局] L494`。

## 2. 范围

- 独立认知责任域，位于 LLM 之上、学业规划层之下；非底层确定性设施、非单一专项 Agent。`[终局] L1894-1903`。
- 判断对象 10 类：位置/目标/差距/路径/任务/教与授/检验/反馈/修正/阶段衔接。`[终局] L1424-1435`。
- **不做**: 判断引擎不能拥有产品根级决定权、不能绕过规划层把候选变生效、不能自行修改产品规则。`[终局] L1499, L496`。

## 3. 三类对象划分

| 对象类别 | 是否必经判断引擎 | 说明 |
|---|---|---|
| 需专业认知的判断对象（10 类） | 是 | 涉及理解/推理/归纳/方案比较 |
| 确定性规则可直接处理 | 否 | 权限/状态迁移/来源登记/不可逆拦截由底层设施强制 |
| 学生可直接决定/提供 | 否 | 学生自身处境/目标意愿/偏好/最终选择 |

`[终局] L1439-1443`。

## 4. 输入 / 输出

| 输入 | 输出 |
|---|---|
| 外部证据 + 内部证据（登记来源）`[终局] L1613` | 结构化判断（含等级/证据引用/不确定/影响范围）`[终局] L1625` |
| 学业对象/材料/问题 | 候选（不经规划层裁决不生效）`[终局] L1626` |
| 判断流程 + 学业限定约束 | 降级/补证/停止信号 `[终局] L1731-1738` |

## 5. 判断流程（候选→裁决）

```text
输入证据（外部/内部，登记来源）
  ↓
理解与组织（阅读理解材料、识别问题）
  ↓
形成判断候选（区分事实/推断/候选/未知）
  ↓
证据校验（比对证据、识别冲突/缺口/过期）
  ↓
强度判定（判断强度是否超过证据支持范围）
  ↓
降级/补证/停止（证据不足按 §8 处理）
  ↓
输出结构化判断（含等级/证据引用/不确定/影响范围）
  ↓
【候选阶段】──→ 学业规划层裁决 ──→ 生效判断/待确认/驳回
```
`[终局] L1611-1626`。

**分工**: 判断引擎=形成并校验候选（会判断的认知层）；学业规划层=最终裁决（承担全局责任的决定层）。判断引擎不能：最终定夺采用哪条路径/没证据时背书/从证据直接生成并自动执行完整规划/冲突时自行选定/绕过规划层把候选变生效。`[终局] L1630-1638`。

## 7. 输出等级定义

| 等级 | 含义 | 约束 |
|---|---|---|
| 事实 | 可直接从证据/客观材料/真实记录定位 | 须有对应证据引用 |
| 分析 | 基于证据的解读与整理 | 标明依据 |
| 推断 | 证据支持但未达确认 | 明确标"推断"，不冒充事实 |
| 候选 | 待裁决备选 | 不自动生效 |
| 未知 | 证据不足以回答 | 明确说"无法判断"，不硬猜 |
| 冲突 | 证据相互冲突 | 展示冲突，不强行归纳 |

`[终局] L1671-1678`。**推断/候选不得伪装成事实（状态升级）；不得用模型自信/流畅/日志证明输出正确。** `[终局] L1682`。

## 8. 降级（必须降级/停止情形）

| 情形 | 处理 |
|---|---|
| 没有足够证据 | 补证或降低强度，请求补充材料 |
| 证据来源冲突 | 展示冲突，不强行归纳；必要时暂停 |
| 证据过期 | 标记待复核或失效 |
| 学业对象身份/阶段不清 | 请求澄清，不硬判断 |
| 判断超学业范围 | 不扩展，交超范围处理 |
| 专项 Agent 输出冲突 | 不静默择一，上报规划层 |
| 规划版本与输入版本不一致 | 冻结，核对版本 |
| 判断引擎/底层规则版本不匹配 | 阻止 |
| 所需权限未取得 | 不执行 |
| 可能高影响或不可逆后果 | 拦截，须权限确认 |
| 违反统一状态/接口/验收规则 | 阻止 |

`[终局] L1717-1728`。降级结果：请求补充材料/降强度/低风险建议/暂不候选/人工确认/暂停/回退。`[终局] L1731-1738`。降级不是失败，是可靠性机制，如实记录。`[终局] L1740`。

## 9. 超范围处理（三条硬规则）

1. **不扩展**: 超学业对象不自行生成/扩大判断范围；2. **不伪装**: 不把超范围内容包装成专业结论；3. **不越权**: 涉及心理/医疗/安全/法律停止自动判断并转交。`[终局] L1781-1786`。高风险交叉信号 → 按预定义路径转人工/教师/机构/监护或专业求助。`[终局] L1776`。

## 10. 判断引擎与相邻对象边界

- **vs LLM**: LLM 提供通用能力；判断引擎叠加学业限定收敛；判断引擎不是另一个大模型、不是单纯提示词集合。`[终局] L1832`。
- **vs 底层确定性设施**: 判断引擎"会判断"；底层设施"决定是否能生效"（身份/隔离/状态迁移/证据字段/不可逆拦截等代码强制）。`[终局] L1834`。
- **vs 专项 Agent**: 判断引擎规定专项判断统一契约；专项 Agent 领域内执行；规划层整合、承担最终责任。`[终局] L1836`。
- **vs 监察**: 监察核验判断依据/是否越权/是否伪证/降级到位，不替代判断；监察结果接受上级治理。`[终局] L1838`。
- **vs 学业规划**: 判断引擎"会判断的认知层"；学业规划"承担全局责任的决定层"；不能绕过规划层。`[终局] L1840`。

## 11. 完成定义

判断引擎能对 10 类判断对象基于客观真实证据形成受约束结构化判断，具备学业限定、证据要求、判断流程、输出等级、降级、超范围处理，且与 LLM/底层/专项 Agent/监察/规划层边界清晰。`[终局] L1904`。

## 12. 验收标准（L1/L2 首版可验）`[终局] L1907-1916`

1. 对 10 类对象走完 证据→候选→校验→强度→降级→输出→裁决→生效；2. 判断基于客观证据，可追溯完整证据链；3. 判断强度不超过证据支持范围；4. 推断/候选不伪装事实、未知如实、冲突不强行归纳；5. 证据不足/冲突/过期/超范围正确降级补证停止；6. 超学业范围不扩展；7. 不拥有路径裁决权，候选不经裁决不生效；8. 专项 Agent 遵守统一判断契约；9. 监察能核验判断依据；10. 未经验证能力标 `[待验证]`。L3/L4 `[待验证]`。
