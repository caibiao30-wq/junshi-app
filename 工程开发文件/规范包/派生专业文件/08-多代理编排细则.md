## 1. 目的

把"全局-局部 Agent 体系"落到可代码的编排契约：总军师统筹完整学业全局，单一学科军师组织学科内，专项 Agent 处理具体内容，横向责任域 Agent 提供支撑；学生只面对统一入口，不暴露内部 Agent 拓扑。`[终局] L2736-2757`。

## 2. 范围

- 覆盖 Agent 分层、统一契约、编排原则、协作交接、冲突规避。`[终局] Q7-2, Q1-4, Q6-4`。
- **不做**: 不决定具体学科专家数量/内容；多 Agent 协作是否降低认知负担为 `[待验证]`。

## 3. 全局-局部 Agent 体系（[用户明确判断] 战场比喻）

> 学业是多学科的集合，存在全局与局部区分：全局=完整学业（全学科），局部=单一学科及其下属内容。学业军师=总军师 + 单一学科军师 + 专项 Agent + 各部门 Agent。`[终局] L2730`。

```text
学生
  ↕
总军师（全局军师 / 完整学业 / 全学科）
  ├── 负责全局目标、优先级和总体路径
  ├── 负责跨学科资源与任务协调
  ├── 负责接收各层专业意见
  └── 负责统一对学生表达
          │
          ├── 单一学科军师
          │     ├── 负责该学科整体位置与路径
          │     ├── 负责学科内目标、差距和任务组织
          │     └── 协调该学科下的专项 Agent
          │
          ├── 其他责任部门 Agent（证据/判断/教与授/反馈与检验/学业资产/监管等）
          │
          └── 学科专项 Agent（负责学科内具体内容，提供专业判断与执行支持）
```
`[终局] L2736-2755`。

## 4. Agent 分层责任边界

| 层 | 主要责任 | 不能 |
|---|---|---|
| 总军师 | 全局目标/优先级/总体路径/跨学科协调/统一表达 | 不凭空压过局部事实，须接受学科与专项证据约束 |
| 学科军师 | 学科整体位置/路径/目标/差距/任务组织 | 不各自形成互冲突的完整规划 |
| 学科专项 Agent | 学科内具体内容专业判断/执行支持 | 不决定全局路径/阶段目标/优先级 |
| 横向责任域 Agent | 证据/判断/教与授/反馈/资产/监管跨学科支撑 | 局部优化不突破全局目标 |

`[终局] L2757-2761, L472`。

## 5. Agent 统一契约字段（可落 schema）`[终局] L568`

| 字段 | 说明 |
|---|---|
| `main_responsibility` | 唯一主责对象 |
| `applicable_stage_subject` | 适用学段/学科/场景 |
| `input_types + min_permissions` | 输入类型和最小权限 |
| `evidence_read_scope` | 可读取证据范围 |
| `writable_objects` | 可写入对象 |
| `output_structure + judgment_level` | 输出结构和判断等级 |
| `not_responsible_for` | 不负责内容 |
| `interfaces[]` | 与其他 Agent 输入输出接口 |
| `failure_conflict_uncertainty` | 失败/冲突/不确定处理 |
| `version_dependency` | 版本依赖/模型配置 |
| `completion + acceptance` | 完成定义和验收标准 |
| `refusal_degrade` | 责任范围外的拒绝与降级 |

无契约的 Agent 不得接入生产协作。`[终局] L568`。

## 6. 编排原则 `[终局] L3138-3145`

1. 统一入口——学生只面对统一入口；2. 总军师统筹；3. 学科军师局部；4. 横向责任域跨学科支撑；5. 证据与状态共享——所有 Agent 读取同一套有效证据和状态；6. 候选不生效——Agent 输出先入候选，规划层裁决后才生效。

## 7. 协作与交接流程

```text
学生 → 统一入口 → 总军师
  ├── 调度 → 单一学科军师 → 学科专项 Agent
  └── 调度 → 横向责任域 Agent（证据/判断/教与授/反馈/资产/监管）
```
`[终局] L3148-3156`。交接保留：来源/学生/学科/责任域/证据/版本/影响范围/待决事项/完成状态。`[终局] L3158`。

## 8. 冲突与局部最优规避 `[终局] L3160`

- 所有 Agent 读同一套有效证据与状态；所有输出带责任域/版本/证据引用/影响范围；规划相关建议先入候选；总军师统一整合，判断引擎检查证据边界；冲突意见不得静默择一；重大冲突暂停相关规划变更并请求裁决（规划层/必要时人工）；局部优化不得突破全局目标；只有规划层能把候选路径变成生效规划；所有冲突与裁决可回溯。

## 9. 编排的确定性控制 `[终局] L3162`

谁在何时可调用谁、读什么、写什么、交接是否合法、是否越权，均由底层确定性设施校验，不靠 Agent 自觉。

## 10. 完成定义

总军师/学科军师/专项/横向责任域 Agent 能按统一入口、总军师统筹、证据状态共享、候选不生效原则协作交接，避免冲突与局部最优；编排受确定性设施约束。`[终局] L3164`。

## 11. 验收标准（L1/L2 首版可验）`[终局] L3166-3175`

1. 学生只面对统一入口；2. 总军师统筹完整学业，学科军师组织学科内；3. 所有 Agent 读取同一套有效证据与状态；4. Agent 输出先入候选，规划层裁决后才生效；5. 冲突意见不静默择一；6. 局部优化不突破全局目标；7. 交接保留来源/证据/版本/影响/责任；8. 编排越权由确定性设施阻断；9. 多 Agent 协作确实降低而非增加学生认知负担（`[待验证]`）。
