# 唯一状态源与生命周期细则（状态设施）

> **inherits_from**: `JUNSHI-ENG-MASTER-001`
> **版本**: v1.0 · **2026-09-15** · **地位**: 不可替换自持核心 · **母源**: 工程开发总文件 §5.1/§6.4
> **权威锚**: `[终局]` = `访谈资料/学业军师终局访谈/02_访谈记录.md`

## 1. 目的

确立学业军师唯一状态源与生命周期：每种对象有语义清晰的状态模型、合法迁移必须经校验、候选与生效分离、模型只能提候选不能直接改状态、异常状态产品内部降级隔离撤回回滚。`[终局] L2700`。

## 2. 范围

- 覆盖对象状态：证据、判断、规划、任务、资产、适配、权限。`[终局] L2676`。
- 状态迁移触发来源：外部证据进入/撤回、内部行动/任务/检验、判断候选、规划裁决、学生确认/拒绝/暂停/纠正、生命周期到期/复核、Harness/监管发现异常、恢复/撤回/回滚。`[终局] L2694`。
- **不做**: 回滚业务语义（G1）本文件只给状态迁移边界，业务回滚定义在 `07-业务回滚语义细则.md`，且 `[待用户拍板]`。不叠加多状态框架。

## 3. 唯一状态源原则

单一权威状态源；避免同时叠加多个框架/状态层/记忆系统。`[CLAUDE 工程目录] 规范包与交付`。状态由确定性设施承载，不靠模型/提示词。`[终局] L2692`。

## 4. 各对象状态维度

| 对象 | 状态枚举 |
|---|---|
| 证据 | 来源明确/完整/可使用/待补证/冲突/受限/撤回/失效 |
| 判断 | 事实/分析/推断/候选/未知/冲突 |
| 规划 | 草案/候选/生效/暂停/回退/结束/失效 |
| 任务 | 未开始/进行中/已提交/检验中/完成/阻塞/取消 |
| 资产 | 候选/待确认/阶段内有效/待复核/失效/撤回/归档 |
| 适配 | 观察中/试用中/采用/限制/撤回/恢复 |
| 权限 | 当前角色是否有权读取/写入/确认/删除 |

`[终局] L2676`。

## 5. 状态迁移合法性检查

```text
当前状态 + 触发事件 + 证据/权限条件
                    ↓
             迁移合法性检查
             ├── 允许迁移
             ├── 降级或待确认
             ├── 暂停/隔离
             └── 拒绝
                    ↓
                新状态
```
`[终局] L2680-2692`。

**模型/Agent 不能直接绕过状态规则**: 模型不能把候选判断直接写成生效判断；任务生成≠任务完成；学生点击≠充分理解；一次检验结果≠自动形成长期资产；过期/撤回证据不能继续支持高影响状态；低风险局部变化不能静默升级为全局规划变化。`[终局] L2692`。

## 6. 迁移记录字段（可落 schema）

每次迁移至少保留：`from_state`、`to_state`、`trigger_event`、`evidence_refs[]`（外部/内部）、`triggered_by`（责任域）、`time`、`version`、`impact_scope`、`reason`、`downstream_effects`、`rollback_condition`。`[终局] L2694`。

## 7. 自动迁移 vs 受限迁移

| 层次 | 处理 |
|---|---|
| 当前交互临时状态 | 产品内部自动处理 |
| 单个学生低风险可逆状态 | 自动处理，保留纠正/暂停/拒绝入口 |
| 局部任务/学科状态 | 自动处理，需证据/权限/影响范围检查 |
| 影响规划/资产/多个责任域 | 进入候选/限制/隔离/内部监管流程 |
| 影响根级责任/证据规则/权限安全/学生主体 | 运行时拒绝并隔离，不得自主迁移 |

`[终局] L2696`。"受限迁移"是产品内部自动控制+监管，不等于逐项人工批准。

## 8. 状态冲突与错误处理

- 冲突不静默选择一个状态覆盖另一个，保留冲突双方及来源。`[终局] L2698`。
- 限制冲突状态向下游传播；降低相关判断强度；暂停受影响高影响动作；继续用上一稳定状态处理低风险事务；通过新证据和内部检查重新判断；必要时撤回/隔离/回滚。`[终局] L2698`。
- 状态机本身也须接受监管，不只验"形式合法"，还验是否符合证据/责任/权限/学生控制。`[终局] L2698`。

## 9. 完成定义

为不同对象建立语义清晰状态模型，所有重要状态迁移有明确触发条件、证据依据、权限检查、影响范围和回溯关系；模型只能提候选，确定性设施与内部监管共同决定迁移是否合法；异常状态产品内部降级/隔离/撤回/回滚。`[终局] L2700`。

## 10. 验收标准（L1/L2 首版可验）`[终局] L2702-2712`

1. 证据/判断/规划/任务/资产/适配/权限状态可区分；2. 模型输出不能直接绕过状态迁移规则；3. 每次重要迁移保留原状态/目标/触发/证据/版本；4. 自动与受限迁移边界明确；5. 候选判断不自动变生效或长期资产；6. 撤回/失效/删除触发下游状态检查；7. 状态冲突不静默覆盖；8. 高影响/根级状态不由运行时自主改变；9. 状态机异常由产品内部 Harness 处理，不形成用户个案人工升级；10. 状态机制/稳定性/隐私安全/教育效果分别验证。
