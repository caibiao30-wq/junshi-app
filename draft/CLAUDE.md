# draft 文档协作规则

## 身份与边界

`draft/` 保存学业军师产品的阶段性材料、研究输入和历史过程记录；不定义当前 Super Vibe Coding 系统，也不自动构成产品或工程权威。

`draft/` 中的内容必须区分早期设想、阶段性判断、候选方案、研究证据和待确认事项。目录存在、文档标题、历史“最终”措辞或旧决策登记均不得自动升级为当前有效决定。

## 当前工作顺序

学业军师产品工程开发（已授权，进行中）与 Super Vibe Coding 系统是两条并行、互不门控的工作流（见根 `CLAUDE.md`）。除非任务明确要求提取学业军师历史材料，不得让 `draft/` 内容反向决定任一条主线或当前工程文件的结构；`draft/` 本身不构成产品或工程权威。

## 读取纪律

- 进入 `draft/` 前先读根 `CLAUDE.md` 与本文件。
- 只读取完成当前任务所需的文件，不默认通读 `draft/`。
- 读取时标明来源文件、材料状态和使用目的。
- 不引用已删除的 `mate/`，不假设 `book/` 或其他旧目录仍存在。

## 写入纪律

- 默认只读；未经明确授权不得修改本目录。
- 不把草稿、研究报告、代码现状或 Agent 推论写成产品决策。
- 发现版本、状态、来源或权威冲突时暂停并报告，不自行裁决。
- 任何从 `draft/` 提取的内容，在进入当前系统或产品正式文件前都必须重新确认其状态和适用范围。

## 交付检查

- 已区分早期材料、阶段性材料、研究证据和当前确认。
- 未引用已删除目录或过时权威链。
- 未把 `draft/` 内容越级为 Super Vibe Coding 系统规则。
- 未修改未获授权的文件。
