## 1. 配置项分类

### 1.1 核心配置（必须）

| 配置项 | 文件 | 必要性 | 说明 |

## 2. 权限范围详解

### 2.1 工具权限

| 工具类型 | 权限配置 | 推荐默认 |
|----------|----------|----------|
| **Bash** | 命令白名单/黑名单 | `acceptEdits` |
| **Edit** | 文件路径模式 | 允许 |
| **Write** | 文件路径模式 | 允许（需确认） |
| **Read** | 无限制 | 允许 |

### 2.2 Bash 权限模式

```
# 允许特定命令
Bash(git status:*):true
Bash(git diff:*):true
Bash(ls:*):true

# 允许所有命令（谨慎）
Bash(*):true

# 禁止危险命令
Bash(rm -rf /:*):true
Bash(sudo:*):true
Bash(curl | bash:*):true
```

### 2.3 文件权限模式

```
# 允许编辑特定目录
Edit(src/**):true
Write(src/**):true

# 禁止编辑配置文件
Edit(.claude/settings.local.json):false
Write(.claude/settings.local.json):false
```

## 3. 钩子触发范围

### 3.1 PreToolUse 钩子

**触发时机：** 工具调用前  
**用途：** 权限检查、输入验证、日志记录

| matcher 模式 | 匹配工具 | 示例用途 |
|--------------|----------|----------|
| `Edit\|Write` | Edit、Write | 只读守卫、文件锁定 |
| `Bash` | Bash | 命令审计、危险操作拦截 |
| `*` | 所有工具 | 全局日志、性能监控 |

### 3.2 PostToolUse 钩子

**触发时机：** 工具调用后  
**用途：** 结果处理、状态更新

| matcher 模式 | 匹配工具 | 示例用途 |
|--------------|----------|----------|
| `Write` | Write | 文件变更通知、自动格式化 |
| `Bash` | Bash | 命令结果记录、性能统计 |

### 3.3 Stop 钩子

**触发时机：** 智能体停止时  
**用途：** 清理工作、保存状态

| matcher 模式 | 示例用途 |
|--------------|----------|
| `*` | 保存会话状态、生成工作日志 |

## 4. 自定义命令范围

### 4.1 命令命名规则

- 文件名即命令名：`audit.md` → `/audit`
- 支持子目录：`utils/format.md` → `/utils/format`
- 文件名小写，用连字符分隔：`code-review.md`

### 4.2 命令内容格式

```markdown
# 命令标题

## 任务描述
描述此命令要完成的任务...

## 执行步骤
1. 第一步
2. 第二步
3. 第三步

## 输出格式
- 格式要求...
```

### 4.3 推荐命令清单

| 命令 | 用途 | 触发场景 |
|------|------|----------|
| `/audit` | 审计配置一致性 | 定期检查 |
| `/grill` | 深度追问设计方案 | 设计评审 |
| `/draft` | 进入草稿模式 | 探索性编辑 |
| `/research` | 调研外部资料 | 信息收集 |
| `/review` | 代码审查 | PR 审核 |

## 5. .claudeignore 范围

### 5.1 必须排除

| 模式 | 原因 |
|------|------|
| `node_modules/` | 依赖目录，体积大 |
| `dist/` | 构建产物 |
| `build/` | 构建产物 |
| `*.log` | 日志文件 |

### 5.2 推荐排除

| 模式 | 原因 |
|------|------|
| `.scratch/` | 临时工作目录 |
| `.orca/` | Orca 工作区 |
| `.git/` | 版本控制数据 |
| `*.tmp` | 临时文件 |
| `*.bak` | 备份文件 |

### 5.3 不要排除

| 模式 | 原因 |
|------|------|
| `CLAUDE.md` | 项目指令，必须读取 |
| `.claude/**` | 配置目录，必须读取 |
| `docs/**` | 文档目录，可能需要引用 |
| `src/**` | 源代码，核心工作对象 |

## 9. 智能体记忆范围

### 9.1 记忆分类

| 类型 | 用途 | 示例 |
|------|------|------|
| **决策记录** | 记录重大决策和理由 | `decisions.md` |
| **知识积累** | 存储项目特定知识 | `learnings.md` |
| **模式库** | 已验证的代码/设计模式 | `patterns.md` |

### 9.2 记忆使用原则

1. **只追加，不改写：** 保留历史记录
2. **标记时间：** 每条记录带日期
3. **定期清理：** 删除过时信息
4. **不提交 git：** 本地会话间共享
