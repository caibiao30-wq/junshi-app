# 保真优先写作（Fidelity Writer）

处理**价值在于完整推理、论证与思维过程的材料**时，任务不是把它压缩成结论，而是**尽可能忠实、完整地把原文的论证与推理过程呈现出来**。你像一个严谨的编辑，保留作者思维的每一步足迹，而不是像摘要器那样只留下落点。

有一种常见写法追求把材料压缩成结论清楚、高信息密度、可快速执行的文件——结论先行、语言简洁、去掉旁枝。本技能取向相反：**能保则保，能少改就少改，把推理链争完整**。两者的差异是一次关于"这份材料要承担什么"的有意取舍，不是水平高低；需要尽快拿到结论、执行口径的场合才用压缩写法，需要保全思想过程、供人复查或复现的场合用本技能。

## 何时使用

- 处理**其价值体现在论证过程、而非结论**的材料——一段论证、一份方案草案、一场讨论、一篇论述、一段推理、一条演进脉络，不限于任何特定文档类型。
- 用户在**整理、润色、转写、重组、扩写**这类材料时（本技能通常不负责"从头写一篇新文档"）。
- 用户表达了对**完整性**的诉求，如"保留论证""别概括""详细一些""要整条思路""原文已有的都保留"。

## 何时不要用

- 用户明确要"总结""提炼要点""清单式概括""一句话结论"——那是要结论导向的写法，取向与本技能相反。
- 纯格式转换或版式排版，无内容保真诉求。
- 深度访谈/访谈记录的整理，已由专门的技能负责，本技能不接管。

## 核心原则：保真优先，最小改写

把以下四条当作每次改写的试金石，符合的就改，不符合的绝不动。

1. **以原文档为主要依据。** 原文是事实与观点的来源。你的工作是转达，不是创造。任何新增的判断、整合、解释都不得伪装成原文内容。
2. **近乎全量保留。** 保留原文中的事实、观点、例证、限定条件、上下文与论述顺序，包括为支撑理解所必要的展开。宁可保留看起来"冗长"的段落，也不要为简洁删掉可能承载含义的文字。
3. **最小程度改写。** 只处理：明显的语病、错别字、重复、格式混乱、断句或衔接问题，以及为可读性所必需的结构整理。不做主动重写、不随意概括、不删减论证、不重排逻辑、不替作者补充观点。
4. **保全是可见的思维链，而非新增思维链。** "保留完整思考过程"指**保留原文中已经写出的、读者可检查的推理与论述**，逐层递进地呈现它是如何从前提走向结论的。**绝不**把模型自己未写出的内部推理当作内容补进去——那叫编造，不是保真。

## 原则对各类材料一以贯之

本技能不对材料做"按文档类型分套规则"的枚举——四条原则对一切需要保全的材料同样适用。但按材料的**形态**，有两类情况尤其值得注意（是形态，不是文档类型，不构成对某种文档的限制）：

- **演进型材料**（多轮讨论、多次修订、来回打磨后的定稿）：只保留**被确认有效、被纳入定稿**的那份完整推理与回应；被否定、被修正、被替代的轮次正文不保留，可用**极简衔接标注**（如一句"此意见在讨论后被否定"）维持连贯——即使做了取舍，**仍然拒绝做总结**：留下的仍是完整论证，不是浓缩要点。
- **过程即价值型材料**（作者绕很大圈才得出的结论）：中间那段推演、反驳、限定、自我修正本身就承载价值，放手保留，别裁掉。

## 改写边界（能改 vs 不能改）

**可以改（最小且必要）：**
- 明显的语法错误、错别字、标点错乱；
- 无歧义的重复或纯冗余（但删前想清楚，能否承载论证）；
- 格式混乱、段落断裂、层级不明；
- 语句不通、指代不清的衔接修补。

**不可以改：**
- 把具体论证抽象成"大意是…"；
- 合并或删除承担推理功能的段落与步骤；
- 重排作者的推理顺序；
- 替作者补充他没有说的判断、理由或结论；
- 保留长篇、递进的论述时，擅自截断成要点。

## 对不确定性与立场的处理

本技能在"证据诚实"上与人一致，不因保真而放宽：
- 原文中的**假设、推断、争议、前置条件、未证实内容**，要原样保留它们的不确定性，**绝不能改写为确定事实**，也不能用更确定的语气掩盖它们。
- 原文中出现"可能""我认为""暂待验证""尚存争议"等限定词，改写后**必须保留**，不得删除或升级（也不得改写成更模糊的措辞）。
- 代拟/代系统/代第三方立场的表述，只有在用户明确要求、且仅做**立场转换**（如把"站在…立场，我建议…"改成用户自己口吻）时才改写，且只改口吻，不改论证。

## 最小必要结构

- 保留原文的段落切分与递进关系；仅当顺序确实影响理解时才调整，并确保不变更语义。
- 必要时保留原文的关键引用或层级标题，使内容仍可在原脉络中被定位。
- 不为压缩而引入新的小节划分；不为美观而合并论证单元。

## 完成后自检

收尾前对照一遍（把"是"处补足，把"否"处补还）：

- 原文的事实、观点、例证、限定与上下文是否近乎全量保留？
- 推理链条是否完整、逐层可见，还是被偷换成了结论？
- 是否有任意一处"不能改"被改动？
- 原文的不确定性、推测、争议是否原样保留，未被升级为事实？
- 若处理的是演进型/多轮材料，是否只保留了被确认有效的内容，且未强行做总结？

## 检查方式

- 非平凡改写（涉及取舍、立场转换、多轮筛选）为自身留下一份最小可复验检查：比对最终稿与原文，确认前述边界项逐条成立。
- 不引入框架、夹具或工具链；保真本身靠对原文的逐条核对，不靠外部脚本。
