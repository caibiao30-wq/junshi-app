# 第三章　产品本质与价值（阶段 2）

## 3.1　问题 2-1：产品必须改变用户的什么处境

**标准化问题**：用户在使用产品前最根本的缺失是什么？使用一段时间后最希望真正获得什么？请说明理由和边界。

**回应与论证**：

受访者表示，用户在使用前最根本的缺失不是某个孤立答案，而是不知道自己处在什么位置，也不知道下一步应如何行动。其理由是：用户可能接触了很多信息，却无法将信息组织为针对当前问题的有效行动。

使用一段时间后，用户希望逐步形成理解自身处境、采取行动、观察结果并修正方向的能力。“逐步形成”意味着该判断需要长期使用验证；产品可以提供辅助，但不能使用户离开产品后无法继续。

`[专业建议·代拟]` 采访者据此代拟：报告可围绕“处境判断—行动—观察—修正”展开；受访者尚未确认该表述覆盖全部产品目标。

**长论证零件（保留不压缩）**：前提 = 用户已接触大量信息但缺少组织为行动的方法；条件与限定 = “逐步形成”需长期使用验证、依赖真实反馈；证据等级 = 前述为受访者来源判断，“独立形成能力”为待验证，代拟结构为 `[专业建议·代拟]`，不混写；修正链 = 本条记录未提供早期表述，因此不补造修正；如记录存在后续修正，须保留早期内容并标 `[已被修正]`；反例/例外 = 产品若使用户离开后无法继续，则该目标不成立；未决项 = 该结构是否覆盖全部产品目标。
