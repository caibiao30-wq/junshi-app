# 来源与调查范围 schema（Source & Scope Schema）

本文件定义 `01_调查取证.md` 中"调查范围授权（范围快照）"与"来源登记"的可解析结构，是 [`evidence_scope_gate.py`](../scripts/evidence_scope_gate.py) 逐字段校验的权威依据。落地来源：《interview技能组的优化升级报告》§5（调查范围强制授权门）与 §10（逐节点证据门禁与质检脚本改造）。

**门禁定位**：本 schema 只保证结构可校验；语义正确性（某条"来源事实"是否真的被定位到、推断是否有依据）超出脚本能力，须由 `evidence_scope_gate.py` 输出"需人工复核"并交由主技能/方法学语义审查，脚本不单独放行定稿。

---

## 一、调查范围授权（范围快照）

放在 `## 调查范围` 区块。主技能未提供以下任一关键字段时，应先询问范围、不开始外部取证。字段详情：

| # | 字段 | 说明 | 必填 |
|---|---|---|---|
| 1 | 调查目标与核心问题 | 要摸清什么，最核心的问题是什么 | 是 |
| 2 | 产出用途 | 产出给谁、用于什么决定（信息/证据包，非产品决策） | 是 |
| 3 | 时间窗口 | 取证的起止时间 | 是 |
| 4 | 版本锚点 | 仓库分支/提交点、文档版本 | 是 |
| 5 | 允许的来源类型与平台 | 仓库 / 外部 / 代码 / 用户反馈等类型与平台 | 是 |
| 6 | 平台授权 | GitHub / X / 论文 / 文章 各自是否允许 | 是 |
| 7 | 是否允许联网 | 是否获准联网取证 | 是 |
| 8 | 排除范围 | 明确不读取的来源、目录、域名或材料类型 | 是 |
| 9 | 失败来源处理方式 | 不可访问/冲突来源如何记录（见 §三） | 是 |
| 10 | 调查结束验收条件 | 什么条件下本次取证算完成 | 是 |

---

## 二、来源登记与来源 ID

来源登记表放在 `## 来源登记` 区块。**每个来源必须唯一分配来源 ID**，格式 `SRC-01`、`SRC-02` …，供来源区块、`question_id → evidence_ref[]` 映射和质检引用。

### 来源登记表字段（逐来源必填）

| 列 | 说明 | 必填 |
|---|---|---|
| 来源ID | 如 `SRC-01` | 是 |
| 来源类型 | 仓库文档 / 外部·平台 / 代码 / 访谈 / 用户反馈… | 是 |
| 定位 | 路径或 URL + 章节/行号/消息号 | 是 |
| 获取时间 | 取证获取的日期 | 是 |
| 版本 | 分支/提交/tag/文档版本/发布日期 | 是 |
| 访问状态 | `成功` / `失败·不可访问` / `部分` | 是 |
| 材料状态 | 现状材料 / 历史材料 / 候选/研究 / 待核验 | 是 |
| 证据等级 | 来源事实 / 来源观点 / 调查推断 / 待核验 | 是 |

### 来源区块（`### 来源：<名称> [来源ID]`）

登记表与该来源展开区块一一对应。每个来源区块至少含：来源ID、定位、来源类型、获取时间、版本、权限（是否获主技能授权）、访问状态、材料状态、证据等级、可直接观察的事实、来源作者的判断、调查推断（含依据）、内在张力/缺口、第一性问题候选。

---

## 三、不可访问来源（失败来源）处理

**不可访问来源必须记录为失败，不得静默跳过。** 访问状态取值 `失败·不可访问` 的来源区块须额外包含：

- `失败原因`：错误码/返回状态（如 404、无权限、超时）；
- 明确其承载的内容**不作为既有事实引用**；
- 其承载的问题**转入待核验清单**。

来源缺口（缺来源、缺版本、冲突）一律转为待核验问题，写成"待核验"而非结论。

---

## 四、question_id → evidence_ref[] 映射

放在 `## question_id → evidence_ref 映射` 区块。供 §10 门禁逐问题校验证据引用是否真实存在。

| question_id | evidence_ref[] |
|---|---|
| Q-01 | SRC-01, SRC-02 |
| Q-02 | SRC-03（不可访问·待核验） |

规则：每个 `question_id` 至少一个证据引用；引用必须是已登记且非静默跳过的来源，否则进入待核验。

---

## 五、与验收标准对应

- 范围字段缺任一关键项（§5）→ 先提问，不开始外部取证。
- 每个来源可回溯到路径/URL、版本与获取时间（§5）。
- 不可访问来源记为失败，不静默跳过（§5）。
- 来源缺口自动转为待核验问题，不写成结论（§5）。
- 逐来源校验必填字段、逐问题校验证据引用（§10）。
- 脚本无法判断语义时输出"需人工复核"，不以"通过"代替语义审查（§10）。
