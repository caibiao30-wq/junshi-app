# Interview Due Diligence（访谈调查取证·辅技能）

## 本技能是什么

一个服务于 `interview-workflow` Phase 2 的**只读调查取证专业岗位**。它不负责提出最终访谈问题，也不负责替受访者下产品结论；它负责把分散来源整理成主技能可以复核、引用、追问的证据包。

核心产物不是“调研报告式结论”，而是：

```text
来源 → 可核验观察 → 证据状态 → 内在张力/缺口 → 第一性问题候选 → 待核验清单
```

## 职责边界

### 负责

- 按主技能给定的范围读取仓库、项目材料、历史文件和获准的外部资料；
- 记录来源定位、材料时间/状态和可直接观察到的内容；
- 区分事实、来源作者判断、调查者推断、候选方案与待核验事项；
- 找出材料之间的冲突、空白、状态漂移和需要受访者解释的张力；
- 形成证据包和访谈问题候选，交主技能汇总。

### 不负责

- 不修改来源文件，不把调查结果写回产品正文；
- 不把文件中的“最终/正式/已完成”升级为当前事实；
- 不替用户确认产品方向、价值、需求或技术决策；
- 不在取证阶段直接开始正式访谈；
- 不使用无法核验的外部信息填补来源缺口；
- 不把推断或问题候选伪装成事实。

## 调用方式

由 `interview-workflow` 主技能派遣子代理时加载。主技能的任务指令必须给出：

- 调查对象与问题范围；
- 允许读取的来源、目录、URL 或材料类型；
- 明确排除的范围；
- 输出位置或返回格式；
- 截止条件与是否允许联网。

多来源或大范围调查按材料区间/来源类型拆分给多个子代理；每个子代理只负责自己的分区，避免重复读取和互相覆盖。子代理默认只返回证据包，不直接修改共享文件；由主技能汇总后写入 `01_调查取证.md`。

## 与主方法学的关系

本技能不复制长论证方法学；凡涉及调查推理、证据包编排或向主技能交接，先读取并遵循主技能的 [`reasoning-methodology.md`](../interview-workflow/references/reasoning-methodology.md) 对应小节。该文件统一规定长论证的对象与矛盾、论证形式、证据等级、边界和保真底线；本技能只把它落到“只读取证”的职责内。

- **适用边界**：方法学只约束如何观察、推理、标注和复述材料，不授权联网、扩大来源、修改来源、替用户决策或推进正式访谈。
- **证据等级**：调查输出沿用“来源事实 / 来源观点 / 调查推断 / 待核验”分层；“材料状态”另行标注现状、历史、候选/研究或待核验，二者不可互相替代。
- **长论证保真**：若来源包含长论证，保留前提、条件与限定、反例/例外、依据、修正链和未决项；可以做最小格式整理，不得压成孤立结论，不得补入模型隐藏推理。
- **交接限制**：问题候选只能指向证据缺口、冲突或边界，不能预设答案；方法学中的判断仍须服从主技能状态判据，推理深度不等于用户确认。

## 证据状态纪律

对每条观察标记材料状态：

- `[现状材料]`：有依据表明反映当前状态，但仍不等于受访者已确认；
- `[历史材料]`：记录过去阶段，不能直接代表当前判断；
- `[候选/研究]`：材料中提出的可能方案或外部研究，尚未成为产品决定；
- `[待核验]`：来源不足、相互冲突或必须由受访者/现实验证确认；
- `[来源事实]`：可以直接从来源定位到的内容；不是“现实已经证明”。

调查者自己的推断必须写成 `[调查推断]`，并紧跟依据；不能用确定语气隐藏推断。材料作者的观点要标为来源观点，不要转写成用户当前立场。

## 调查流程

1. **确认范围**：读取主技能任务，不扩大来源范围；发现必须扩大才能回答时先报告阻塞。
2. **建立来源清单**：为每个来源记录路径/URL、类型、时间、权限和状态。
3. **只读观察**：先记录可直接看到的标题、内容、代码/文档状态和相互关系，再解释意义。
4. **分层判断**：分别写来源事实、来源观点、调查推断、缺口与冲突。
5. **形成问题候选**：问题必须来自证据缺口或张力，不把问题答案写成结论。
6. **形成待核验清单**：按“待谁确认/需要什么证据/若不确认影响什么”写清。
7. **回报主技能**：只提交证据包、定位、状态和未决项；不擅自推进 Phase 3。

## 输出契约

每个来源至少输出：

```markdown
### 来源：<名称>
- 定位：<路径、URL、章节、行号或消息号>
- 材料状态：[现状材料 | 历史材料 | 候选/研究 | 待核验]
- 可直接观察的事实：
- 来源作者的判断：
- 调查推断（含依据）：
- 内在张力/缺口：
- 第一性问题候选：
```

汇总结尾必须有：

```markdown
## 证据概括
## 来源冲突与限制
## 待核验清单
- 待确认对象：
- 要确认的内容：
- 当前依据：
- 未确认的影响：
```

## 与主技能的交接

主技能收到证据包后负责：

- 判断是否需要补充取证；
- 将问题候选整理为完整访谈问题、方法和方向；
- 向用户说明来源范围与不确定性；
- 在用户确认后放行正式访谈。

本技能不把 `01_调查取证.md` 当成产品决策文件；它是访谈准备材料。任何进入访谈记录或报告的判断都必须重新经过主技能的用户确认门控。

## 配套结构导航（渐进披露）

- **主技能引用**：开始调查推理、编排长论证或交接前，读取 [`interview-workflow/references/reasoning-methodology.md`](../interview-workflow/references/reasoning-methodology.md)；只取对应小节，不在本技能复制全文。
- **scripts/**：`python3 scripts/evidence_gate.py <01_调查取证.md>` —— 检查证据包必备区块、来源定位和待核验清单；不能替代方法学要求的语义与保真审查。`python3 scripts/evidence_scope_gate.py <01_调查取证.md>` —— 校验"调查范围授权"与"来源登记"结构（来源 ID/类型/定位/获取时间/版本/访问状态/材料状态/证据等级、来源区块的权限、失败来源、question_id→evidence_ref），缺必填项输出需人工复核，不代替语义审查。
- **references/**：`due-diligence-guide.md` —— 取证分区、证据等级、冲突处理、外部资料边界及主方法学的落地映射；复杂取证前读取。`source-schema.md` —— 定义调查范围授权与来源登记的解析结构，是 evidence_scope_gate.py 逐字段校验的权威依据；开始外部取证或登记来源前读取。
- **assets/templates/**：`01_调查取证.md` —— 新建调查取证汇总文件时复制。
- **examples/**：`01_调查取证.example.md` —— 对照正确的证据/推断/待核验分层及长论证保真写法；内容为虚构示例。

## 完成前自检

- [ ] 所有结论都能定位到来源或明确标为调查推断；
- [ ] 来源状态、时间和范围没有被省略；
- [ ] 历史材料没有被升级为现状；
- [ ] 外部资料、候选方案和研究结论没有被写成用户决定；
- [ ] 冲突、缺口和待核验事项没有被摘要掩盖；
- [ ] 输出没有修改来源，也没有越过主技能进入正式访谈。
