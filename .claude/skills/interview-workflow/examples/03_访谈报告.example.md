# 第三章　产品本质与价值（阶段 2）

## 3.1　问题 2-1：产品必须改变用户的什么处境

**标准化问题**：用户在使用产品前最根本的缺失是什么？使用一段时间后最希望真正获得什么？请说明理由和边界。

**回应与论证**：

用户在使用前最根本的缺失不是某个孤立答案，而是不知道自己处在什么位置，也不知道下一步应如何行动。其依据是：用户可能接触了很多信息，却无法将信息组织为针对当前问题的有效行动。

使用一段时间后，用户希望逐步形成理解自身处境、采取行动、观察结果并修正方向的能力。“逐步形成”意味着该判断需要长期使用验证；产品可以提供辅助，但不能使用户离开产品后无法继续。
