# assets/ — 关于本目录为空的说明

interview-qc 是**质检与集成岗位**：它核对 00/01/02/03 的关系，产出带严重度、证据定位和修复建议的质检结论，**不生成任何新的内容工件**（不写访谈约定、不写记录、不写报告）。

因此本技能不需要「产物模板」类资产，`assets/` 当前为空是**有意的规划，不是遗漏**。

## 预留用途

若后续出现可复用、无歧义、且**不会因内容而引入偏差**的质检配置或模板，可放在此处，例如：

- 统一的质检报告头/尾固定格式片段；
- 面向特定来源（如 `01` 调查取证）的核对模板；
- 供 `qc_run.py` 或人工复核复用的检查配置。

## 何时不应放入这里

- **不放大纲类内容模板**（00/01/02/03 骨架由 interview-workflow 的 `assets/templates/` 维护）；
- **不放大段示例正文**（示例放 `examples/`，且标明虚构、非产品结论）。

若有人提议在本目录放内容，先确认它是否属于「质检复用配置」而非「产物模板」；前者才归这里。
