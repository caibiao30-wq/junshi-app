# 示例访谈约定

> 以下内容为虚构示例，非真实产品决策。
> 状态：已确认

## 访谈对象与权限
- 受访者：示例项目发起人
- 决策权与角色：负责项目方向与最终取舍
- 采访者：访谈工作流主技能 Phase 1

## 目标与产出
- 本次访谈要谈清：项目为何存在、服务谁、如何验证
- 产物使用者：项目决策者与后续执行代理
- 读者读完应能：区分已确认判断、候选方案与待验证问题

## 范围与方法
- 访谈范围：动机、用户、价值、边界、机制、验证
- 阶段顺序：背景 → 现状 → 本质 → 角色边界 → 机制 → 实现
- 追问方法：开放问题、因果追问、反例、边界、实例
- 阶段收敛标准：当前阶段关键问题有回应、状态已标注、记录授权已获得

## 明确不谈什么
- 不进入与本次主题无关的领域
- 不在未谈透前进入具体技术选型
- 采访者不代受访者作最终决定

## 记录与保密边界
- 默认记录：受访者明确同意写入的共识内容
- 不记录/保密：受访者临时标为保密的内容
- 是否允许采访者代拟：允许，但代拟不等于确认
