# 长论证方法学（Reasoning Methodology）v2

## 这是什么、何时读

本文件把"长思维链方法学"确定为访谈全流程（提问、代拟、复述、记录、报告）的**统一论证方法准则**。目的不是给访谈套一种固定模板，而是让每一段论证都：先抓住问题的真实对象与矛盾，再选择最贴切的形式展开，并始终保住前提、条件、限定、反例、证据等级、修正链与未决项。

**读取时机**：每次提问、代拟、复述、记录或报告**之前与之后**各读一遍对应小节，据此展开与自检。本文件是判断依据，不是机械清单；该推导时推导、该论述时论述、该给结论时给结论。

**目录**

## 总纲

长论证的第一性：**先认识对象，再展开过程，最后选形式**。顺序不可倒置。

1. **方法内化、不显性挂名**：下列方法只作为思考与追问的来源，不在任何访谈产物中显性声称使用了某一著作或理论，也不在输出里堆砌术语名词。产物里出现的是"由此得出的具体推理与判断"，不是方法名字。
2. **先对象与矛盾，后形式**：先说清问题是什么、为谁、在什么条件下成立，再找对象内部的主要张力，最后才决定用自然论述、推导、表格、分支还是结论。形式服务论证，不反过来约束论证。
3. **以客观事实为基础**：一切结论建立在可核验事实上；产品内部机制、推理推断不能作为自证证据。

## 认识对象

一段论证开始时，先把**对象**认识清楚，而不是急着套结构：

- **现象与本质**：穿透表面措辞与文档既定说法，看真实约束与动机。材料里的"最终/正式/已完成"不自动等于当前事实。
- **矛盾与主要矛盾**：列出对象内部张力，找出**当前最卡进度的主要矛盾**及其主要方面，别把所有张力一视同仁。
- **对立统一**：把看似对立的判断（如短期收益 vs 长期稳健、易用 vs 完整）看成相互依存、可能互相转化的两面，而不是非此即彼。
- **内因与外因**：区分对象自身的内因与外部条件；变化主要由内因决定，外因通过内因起作用。

**判断**：对象认识不清时，先追问"它真正是什么、为谁、为何存在、在什么条件下成立"，不急着产出形式。

## 过程与全局

把对象放回它所在的**过程与全局**中看：

- **全局与局部**：局部判断放回全局权衡，标注取舍与影响范围；一处的正确不等于全局正确。
- **长期与阶段**：区分一时结论与阶段性结论，标注时间边界；一个阶段的结论不自动适用于下一阶段。
- **量变与质变**：注意量的积累如何变成质的改变，也要识别"量变未到质变"时的标志，不过早宣称质变。
- **条件与可能/现实**：把"可能实现"与"现实存在"分开；一个可能只有在条件具备时才转为现实，标注使条件成立或不成立的因素。

## 认识过程

认识本身是过程，不是一次性得到：

- **具体—抽象—具体**：从具体现象出发，抽象出一般判断，再回到具体情境检验其适用性；避免停留在空洞抽象，也避免只停留在个别现象。
- **实践检验**：区分"已知/认为"与"已被现实验证"；认识要接受实践检验。**学校现实是重要检验场**，但某一次、某个学校的观察是特定检验结果，不自动推广为普遍硬结论。
- **证据分级**：事实 / 来源判断 / 调查推断 / 待验证 各归各位，不混淆，不用确定语气掩盖推断。
- **认识发展**：认识会随证据与场景深化；允许并记录认识的修正与演进（见"收束验证"的修正链）。
- **主次**：区分主要与次要、根本与表面，别让次要问题占据主要注意力。

## 论证推演

展开一段论证时的推演方法（按需选择，不是逐个执行）：

这些方法论均为可选工具：可按当前对象、主要矛盾、证据与论证需要调用第一性原理、矛盾论、实践论、认识论以及全局与局部分析，不要求逐一使用，也不得在产物中堆砌方法名。它们不能替代批判过滤、事实核验、逻辑校验等刚性约束；用户合理内容可采纳，不合理内容必须指出并保持客观。

- **第一性**：每轮回到"它真正是什么、为谁、为何存在"，穿透措辞与既定说法。
- **因果链**：把因果链条说清，标出每条边的证据等级；区分真正的因果与仅相关。
- **充分 / 必要 / 边界**：分清必要条件与充分条件，标注成立边界；"有这个才可能"不等于"有这个就一定"。
- **反例与证伪**：主动找反例；一个好的判断能说清"什么证据会推翻它"。
- **归纳与演绎**：从个案归纳时注明样本边界；从原理演绎时注明前提是否成立。
- **类比迁移**：类比只作启发，必须检验被类比双方在关键条件上是否可比，不跨条件搬用。
- **溯因与假设检验**：由现象提出最可能成因（溯因），再把成因当可检验假设，设计能确认或排除它的验证，而非默认成立。

**推演纪律**：每一步推演都要有可回溯的依据；无依据的推论标 `[推断]` 并注明待核验，不写成事实。

## 表达形式灵活选择

每种形式回答"这段内容以什么形态最清楚"，可在一段长论证内按需组合，不用从头到尾锁死一种。**形式由问题决定，不能模板化**。

| 情形 | 优先形式 | 说明 |
|---|---|---|
| 思路在推进、需要交代推理过程 | **自然论述** | 保留论证顺序、转折、自我修正；默认选项，别为加结构而加结构 |
| 存在明确的因果/依赖关系 | **因果链** | 用"因为/所以/条件是"串联，标出每条边的证据等级 |
| 多层推理环环相扣、读者要核对步骤 | **推导图**（可选工具） | 仅当推理层级多、文字易混时才用；每条边都要有依据，空箭头即空论证。推导图不是必须项，不要满篇箭头表格 |
| 多维度并列、强弱可比 | **分层表** | 列维度对比时用；单元格里不塞长论述（放入正文再引用） |
| 需在两选项/两读法间权衡 | **对比** | 摆出取舍、放弃项与适用条件，不预设立场 |
| 判断分情形、条件不同结论不同 | **分支** | 每分支注明前提与边界 |
| 讨论已收敛、对方只要落点 | **结论** | 直接给结论，但必须能指向支撑它的前提与证据；不给孤零零的"拍板" |

**使用规则**：
- **能论述就不必构图**。推导图/表格只有在"这一段不用它就看不清"时才用，绝不因"访谈该有图"而硬加。
- 形式可混合：先自然论述交代推理，中途抓出因果链，末尾以分层表收束对比。
- 推导图必须保留文字依据，或用文字小节承接，不能成为脱离论证的装饰。

## 收束验证

每段长论证收束前，回到第一性核对：

- **回溯第一性**：论证是否仍指向真实对象与主要矛盾，没有被形式带偏。
- **证伪前置**：是否说清"什么证据会推翻本判断"；找不到证伪条件的判断要降低确定度。
- **状态门**：本判断落在哪一态（见 `state-rubric.md` 七态）；推理再深也不是确认。
- **连续独立验证**：结论是否经过可重复、可独立核对的验证，而非一次观察自证。
- **诚实边界**：如实交代已验证 / 未验证 / 需人工确认；不把未验证写成已通过。

### 保真零件（收束时必须齐全）

下列元素是长论证的"零件"，缺一即不完整，加工后必须近乎全量保留：

- **前提**：这段论证依赖哪些假定与条件。
- **条件与限定**：在什么范围/情景下成立；不成立的边界。
- **反例与例外**：什么情况会推翻或削弱它。
- **证据等级**：事实 / 来源判断 / 推断 / 待验证 各归各位，不混淆。
- **修正链**：早期表述如何被后续内容修正，演进轨迹可见。
- **未决项**：尚未想透或需验证的部分，单列保留。

**红线**：
- 不得把长论证压成一句话结论、要点清单或"摘要"当成完整回应。
- 不得删理由、例证、限定、反例、失败路径、犹豫与自我修正。
- 不得把产品内部机制、猜想、待验证当自明事实（机制不能自证）。
- 不得把"可能/我认为/暂待验证/尚存争议"升级为确定事实。
- 不得用推理图中"好看但没有依据"的箭头替代真实依据。
- 旧材料只是问题地图/证据，不代替本次回答；过去谈过或写入过仍要重新问。

## 贯穿动作的触发契约

本方法学在**每一类动作前后各应用一次**：

| 动作 | 应用点 | 怎么做 |
|---|---|---|
| **提问** | 提问前 | 先想清问题对象与主要矛盾；选一两个能在答案里展开的开口（因果、边界、反例、验证）。提问本身不堆术语 |
| **提问** | 提问后 | 检查问题是否指向真实对象，而非"为了问而问"或默认了未经验证的机制 |
| **代拟** | 代拟前 | 首先参考已授权的 `01_调查取证.md`，再做专业过滤、逻辑校验与事实甄别；只按受访者既有立场与已确认材料推演；保留前提、限定与未决；显式标注“代拟”。科学方法论（第一性原理等）仅按需选用，不能替代批判过滤等刚性约束；用户非专业回应不自动构成权威，合理则保留，不合理则指出。证据不足进入 `[待确认]`/`[待验证]`。 |
| **代拟** | 代拟后 | 核对未加入受访者未表达的判断、未把代拟冒充用户观点；经用户确认前不升级；代拟与批判卡片留在 `02_访谈记录.md`，`03_访谈报告.md` 不得绕过 `02` 直接从 `01` 新增内容。 |
| **复述** | 复述前 | 优先还原对方论证过程而非其结论；重复其前提、条件、反例与修正 |
| **复述** | 复述后 | 对照原文检查：推理链是否完整、限定与犹豫是否还在、有无偷换成摘要 |
| **记录** | 写入前 | 用保真零件清单核对被记录的长回应 |
| **记录** | 写入后 | 每段长论证的元素（前提/限定/反例/证据等级/修正/未决）齐全且带定位 |
| **报告** | 起草前 | 以记录为唯一证据源；规划每章每节该用论述/推导/对比的何种形态 |
| **报告** | 起草后 | 自查未压缩长论证、未把摘要当长论证、未升级状态、代拟已标注 |

## 证据与现实边界

- 一切以客观事实为基础；产品内部机制、推理推断不能作为自证证据。
- 学校现实是重要检验场：结论能在真实学习场景中接受检验。但某一次、某个学校的观察是特定检验结果，不自动推广为普遍硬结论；与其相关的边界写清。
- 不做本工作明确排除之事的延伸（如不讨论 Super Vibe Coding、不把个别变现客户/ B2B 说明扩写成产品方案内容）。

## 与其他契约的关系

- **状态**：本方法学产出的判断仍套用 `state-rubric.md` 的七态；推理再深也不是确认。
- **保真**：`fidelity-contract.md` 的逐段验收与本文件的零件清单互为补充；文件各管其责。
- **路由**：本方法学的核心应用点是主技能的提问/代拟/复述与各辅技能加工；决定派谁执行仍走 `routing-contract.md`。
