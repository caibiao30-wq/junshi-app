# 工件契约

## 目录契约

```text
访谈资料/<本次访谈名>/
├── 00_访谈约定.md
├── 01_调查取证.md
├── 02_访谈记录.md
└── 03_访谈报告.md
```

原始未删减底稿不由本技能覆盖或改写；记录与报告通过原始消息编号、段落锚点或相对路径回溯。

## 00_访谈约定

必须说明：访谈对象与角色、访谈目标、读者与用途、阶段与方法、收敛门槛、记录边界、保密/不记录规则、是否允许代拟。未经用户确认，不进入正式访谈。

## 01_调查取证

每条材料按以下字段记录：

```text
来源：<路径/URL/材料名>
材料状态：现状 | 历史 | 候选 | 待核验
观察/结论：<只写来源支持的内容>
第一性问题候选：<供访谈确认，不写成事实>
```

文件末尾必须有“待核验清单”，并区分事实、推断、用户待确认判断。

## 02_访谈记录

保持访谈阶段与问题推进顺序。每个问题单元至少包含：

```markdown
### 问题 N-M：<主题>
**问题**：<原问题的最小必要整理>
**长篇回应**：<全量保留可见论述；代拟单独标注>
**确认状态**：[状态]
**原始定位**：<消息编号/路径/锚点>
```

一次完整无误的问答可整体转写；同一问题多轮展开时可合并成连贯单元，但不得删去推理、条件、反例、修正或状态变化。

## 03_访谈报告

报告为**正式章/节结构**的正式报告，证据源只能是 `02_访谈记录.md`（拒绝自证，不以报告自身取证）。

**章/节映射**：章=阶段，节=问题。
- 章号 = 阶段号 + 1：第一章←阶段0、第二章←阶段1、第三章←阶段2、第四章←阶段3、第五章←阶段4、第六章←阶段5。
- 节号格式 `章号.问题序号`，节标题保留原始问题编号，例 `3.1 问题 2-1：<主题>`。

**必含结构顺序**：标题与文档状态 → 总目录 → 阅读说明 → 结论总览（正文前） → 第一章~第六章正文（每节含 标准化问题 / 回应与论证 / 节内确认状态 / 记录定位） → 文末：结论边界 → 待确认清单 → 待验证清单 → 回溯索引（报告章/节→记录→底稿） → 附录（状态与代拟说明）。

**双层状态**：每节内保留具体确认状态；文末以「结论边界 + 待确认清单 + 待验证清单」做全报告汇总。

**不编造空章**：有 `02_访谈记录.md` 内容才写入正文；某阶段无记录则相应章不虚造正文，仅作说明。

## 变更与门控

- `00` 用户确认后才放行取证。
- `01` 取证完成、问题/方法/方向经用户确认后才进入正式访谈。
- `02` 每阶段增量写入，用户确认记录增量后才放行下一阶段。
- `03` 全部访谈完成后生成，质检通过后才标记定稿。
