# 示例：未调辅技能不得放行（虚构示意）

> 以下仅演示 interview-workflow 的硬路由行为，不代表真实访谈状态或产品判断。

场景：阶段 3 结束，现场缓冲中有一条新增回应。主技能若只自行编辑 `02_访谈记录.md`，不得把阶段标记为完成。

## 调用账本

- 动作/阶段：记录固化 / Phase 3.5
- 判据：必须派遣
- 目标辅技能与实际入口：`interview-transcriber` / 未调用
- 输入范围：阶段 3 新增回应、目标 `02_访谈记录.md`、本次记录授权
- 输出与状态：无合格交接
- 失败/阻塞：未调用对应辅技能
- 降级事实：无；尚未证明辅技能不可用，也未取得降级授权
- 放行判定：**阻塞 / 未完成**

## 门控结果

主技能不得以“内容很短”“自己能写”或“只是补一段”为理由写入并进入下一阶段。必须先调用 `interview-transcriber`；transcriber 还须先对整份 `02_访谈记录.md` 做全量健康核对并返回增量、授权、定位、状态与阻塞项。只有主技能展示合格交接并取得阶段记录确认后，才可放行。

若辅技能确实不可用，须先记录失败证据并取得授权，才能按同一交接契约走降级；降级事实和复核条件不得省略。
